# ตรวจรับ — #271 ปุ่มในคอลัมน์ดำเนินการเป็นไอคอน

[#271](https://github.com/khthana/Deep-QA/issues/271) คืนคอลัมน์ปุ่มของจอที่ส่งมอบ
(`DEEP-QA-FRONTEND/src/components/BT.js`) — ไอคอนในกรอบสี่เหลี่ยมมุมมน แทนคำ ใต้หัวคอลัมน์
*ดำเนินการ* ที่จัดกึ่งกลาง ทุกจอวาดผ่านคอมโพเนนต์เดียว `frontend/src/components/RowAction.js`

**คำไม่ได้หายไป มันย้ายที่** — คำที่เคยอยู่บนหน้าปุ่มเป็น `aria-label` (ชื่อที่โปรแกรมอ่านหน้าจอพูด
และที่ทุก spec ในชุดใช้หาปุ่ม) และเป็น `title` (tooltip) ถังขยะสี่ใบ — *ลบ* *นำออก* *ยกเลิกการเปิด*
*ยกเลิกบทบาท* — แยกกันได้ด้วยสองอย่างนี้เท่านั้น

## สิ่งที่ตั๋วไม่ได้เขียน และวัดได้ตอนลงมือ (10 พ.ย. 2569)

- **จอนักศึกษาในตอนเรียน (`SubjectStudents.js`) เป็นไอคอนอยู่แล้ว** — ถังขยะ `HiOutlineTrash`
  ไม่มีกรอบ ชื่อ `นำ <รหัส> ออกจากตอนเรียน` ใบนี้เปลี่ยนให้ใช้ `RowAction` ตัวเดียวกับจออื่น
  ชื่อเดิมคงไว้ เพราะมันบอกว่าเอาใครออก ซึ่งคำว่า *นำออก* เฉย ๆ ไม่บอก
- **จอข้อมูลผู้ใช้งานมีปุ่มที่สองที่ตั๋วไม่ได้นับ** — *ระงับ* / *เปิดใช้งาน* จอที่ส่งมอบวาดสถานะบัญชีเป็น
  สวิตช์ในคอลัมน์ของตัวเอง จึงไม่มีไอคอนให้คืน ถามเจ้าของงานเมื่อ 10 พ.ย. 2569 ตอบ **ไอคอน** —
  *ระงับ* เป็น `MdBlock` กรอบส้ม *เปิดใช้งาน* เป็น `MdOutlineCheckCircle` กรอบเขียว ชื่อกับ tooltip
  เป็นคำเหมือนปุ่มอื่น และแถวของบัญชีตัวเองยังวาดปุ่มที่ปิดไว้พร้อมเหตุผลใน tooltip (#84)

## รายการที่ต้องเดิน

ช่องสุดท้ายมีสี่ค่า

- **☑** เดินด้วยมือจบแล้ว หรือพิสูจน์ที่ seam HTTP แล้ว — **สองอย่างนี้เป็น ☑ เท่ากัน** ⚙ สงวนไว้ให้ browser seam เท่านั้น และแถวบอกเองว่าอะไรพิสูจน์มัน (`CLAUDE.md` §Marks on the sheets · [#194](https://github.com/khthana/Deep-QA/issues/194))
- **◐** เดินไปได้ครึ่งเดียว อีกครึ่งยังไม่ได้เดิน — **แถวนั้นบอกไว้เองว่าครึ่งไหนยังขาด และครึ่งนั้นรออะไร** · ส่วนใหญ่ครึ่งที่เดินแล้วคือครึ่งของ server และครึ่งที่เหลือคือสิ่งที่หน้าจอวาด (แถบสี ตาราง dropdown) ซึ่งยังต้องมีคนดู — **แต่นั่นเป็นกรณีที่พบบ่อย ไม่ใช่นิยาม** ครึ่งที่เหลือรออยู่สามอย่าง คือ **คน** (เช่น attribute ที่ไปถึง DOM แล้ว แต่ยังไม่มีใครเปิดโปรแกรมอ่านหน้าจอฟัง) · **ตั๋ว** ซึ่งแถวจะอ้างเลขไว้ · หรือ **ไม่รออะไรเลย** เพราะไม่มีตัวควบคุมบนจอสร้างคำขอนั้นได้ ซึ่งเป็น ◐ ถาวรโดยโครงสร้าง — **สามอย่างนี้นับแยกกัน** (`CLAUDE.md` §Marks on the sheets · [#157](https://github.com/khthana/Deep-QA/issues/157))
- **☐** ยังไม่ได้เดิน
- **⚙** ครอบคลุมด้วย browser seam แล้ว (#65) ไม่ต้องเดินด้วยมือซ้ำ แถวบอกไฟล์ที่ครอบคลุมไว้ และมาร์กนี้ได้มาเมื่อมัตแตนต์ฆ่า assertion ของแถวนั้นเอง — **ถ้าแถวนั้นพูดถึงสิ่งที่วาดด้วย (เมนู ถ้อยคำ สี) ครึ่งนั้นยังเป็นงานของคนเดิน และแถวจะเขียนกำกับไว้** (`CLAUDE.md` §Two test seams · [#194](https://github.com/khthana/Deep-QA/issues/194))

แถว ⚙ สิบเอ็ดแถวแรกพูดข้ออ้างเดียวกันกับสิบเอ็ดที่ — ชื่อของปุ่มคือคำ tooltip คือคำ หน้าปุ่มไม่มีคำและมีไอคอนหนึ่งตัว —
ทุกที่ใช้คอมโพเนนต์เดียว มัตแตนต์ตัวเดียวจึงฆ่าทั้งสิบเอ็ด และสิ่งที่แต่ละแถวเพิ่มคือทางเข้าของจอตัวเองไปถึงคอมโพเนนต์นั้น
จอที่ยังวาดปุ่มคำแบบเดิมจะทำให้แถวของตัวเองแดงและปล่อยอีกสิบแถวเขียว (#191) มัตแตนต์อยู่ที่ `mutation/271-action-icons.py`
