# ตรวจรับ — #336 เดินมือ หน้าตาของ #312–#320

[#336](https://github.com/khthana/Deep-QA/issues/336) — รอบรวมของ #312–#320 ที่เจ้าของงานขอให้ทำทีเดียว (27 พ.ย. 2569) ·
แถวที่เป็น**พฤติกรรม**ถือไว้ที่ browser seam แล้วในรอบเดียวกัน ใบนี้มีเฉพาะครึ่งที่เครื่องตอบไม่ได้ คือ**หน้าตา** · ทุกแถวชี้กลับไปที่
แถวของใบรับงานที่มันปิด และจะติ๊กที่นั่นจากสิ่งที่ผู้เดินบอก ไม่ใช่จากโค้ด

**เขียน 28 พ.ย. 2569 และยังไม่ได้เดิน** — เจ้าของงานขอให้เขียนไว้ก่อน ข้อมูลข้างล่างอ่านจาก schema `deep_core` วันนั้น
ถ้าเดินวันอื่น อ่านข้อมูลใหม่ก่อน (เลขภาคและกลุ่มเรียนเลื่อนได้)

## ตั้งต้น

- เปิด backend ของการเดิน (`cd backend && node server.js` พอร์ต 3000) **ใหม่** ก่อนเริ่ม เพราะมันไม่ reload ตัวเอง · frontend
  `cd frontend && npm start` พอร์ต 3200 · วันที่เขียนไม่มีทั้งสองตัวรันอยู่
- ความกว้างหน้าต่าง 1280px · รหัสผ่านทุกบัญชีตาม seed
- ไม่มีขั้นไหนบันทึกหรือลบข้อมูล — ทุกฟอร์มปิดด้วย *ยกเลิก* และการนำเข้าใน ค2 ถูกปฏิเสธทั้งแฟ้ม (นำเข้าทั้งหมดหรือไม่นำเข้าเลย)
- ข้อมูลวันที่เขียน: ภาควิชา 2 (`01` `05`) · หลักสูตร 3 (`0101` `0501` `0503`) · บัญชี 13 · `teacher.one@` สอนกลุ่มเรียน 1 ของ
  `01076105` สี่ภาค (section_id 1 3 4 6) · section 1 มีกลุ่มงาน 8 กลุ่ม กลุ่มละ 7–8 คน · หลักสูตร `0101` และ `0503` ไม่มีนักศึกษา ·
  **ทุกกลุ่มเรียนมี CLO 9 ข้อและกิจกรรม 5–6 รายการ** ซึ่งทำให้ ฉ2 เดินไม่ได้ด้วยข้อมูลนี้ (ดูที่แถวนั้น)

ถามแบบความรู้สึก (#229) ไม่ใช่ *ถูกไหม* เมื่อแถวถามว่า *อ่านเป็น…* · แถวที่ถามว่า *เหมือน X ไหม* ตอบว่า **เหมือน · ต่าง (บอกว่าตรงไหน)**
