## สิ่งที่ต้องเข้าใจก่อนเดิน — grain กลับด้านจากเพื่อนทั้งเมนู

**แผนการสอนเป็นของตอนเรียน ไม่ใช่ของการเปิดสอน** #27–#30 ทุกใบพูดประโยคเดียวกันว่า
*ทุกตอนเรียนใช้ชุดเดียวกัน* — ใบนี้คือหน้าเดียวที่พูดตรงข้าม: `course_syllabus.section_id`
ถือ grain ไว้ตรง ๆ สองตอนเรียนของการเปิดสอนเดียวถือแผนคนละชุด และ route จึง import
`sectionOf` จาก `enrolment.js` (คำถาม "ตอนเรียนนี้ของฉันไหม" หยุดที่ตอนเรียน — #104)
ไม่ใช่ `offeringOf` ซึ่งจะทำให้ทุกตอนเรียนอ่านแผนร่วมกันเงียบ ๆ seed ทำให้ grain อ่านได้
จากแถวเอง: ทุกหัวข้อลงท้ายด้วย `(ตอนเรียนที่ N ปีการศึกษา Y)`

**เลขสัปดาห์เป็นของคน ไม่ใช่ของเซิร์ฟเวอร์** ลูก ๆ ของ CLO (#28/#29) ให้เซิร์ฟเวอร์แจกเลข
เพราะเลขของพวกมันคือตำแหน่ง — เลขของใบนี้คือสัปดาห์ตามปฏิทิน: พิมพ์เอง แก้ได้ ซ้ำได้
(หนึ่งสัปดาห์สองหัวข้อ — migration 0002 จงใจไม่ตั้ง unique บน `(section_id, week_no)`)
และลบสัปดาห์ 2 ไม่ทำให้สัปดาห์ 3 กลายเป็น 2 ฟอร์มจึงมีช่องเลขที่ฟอร์มพี่น้องจงใจไม่มี
สิ่งที่เซิร์ฟเวอร์ยังถือคือ**ทรง**: จำนวนเต็มบวกที่ลง smallint ได้ ตรวจในโค้ดเพราะ 22003
ที่ไปถึง error handler คือ *เกิดข้อผิดพลาดในระบบ* สำหรับนิ้วพลาด

**ด่านลบเข้มกว่า schema และนั่นคือประเด็น** `activities.course_syllabus_id` เป็น SET NULL
(0003: เขียนแผนใหม่ไม่ควรพากิจกรรมไปด้วย) — DELETE ที่ไม่มีด่านจะตอบ 204 แล้วปลด
กิจกรรมจากสัปดาห์เงียบ ๆ route จึงปฏิเสธพร้อม**เลขสัปดาห์ในประโยค** (`weekInUse`)
แบบเดียวกับที่ #30 เอ่ยชื่อหมวด seed ผูก **สอบกลางภาค** ไว้กับสัปดาห์ 1 ของทุกตอนเรียน
เพื่อให้ด่านนี้มีของจริงให้ปฏิเสธ

**ด่านอยู่ใน DELETE เอง ไม่ใช่ SELECT ก่อนหน้า** — ของ #30 ถามด้วยคำสั่งแยกได้เพราะมี
RESTRICT รองอยู่ข้างล่าง ของใบนี้ไม่มีอะไรรองเลย ช่องว่างระหว่าง "ถาม" กับ "ลบ" จึงเป็นช่อง
ที่กิจกรรมซึ่งถูกผูกเข้ามาพอดีจะถูกปลดทิ้งเงียบ ๆ — คือความเสียหายที่ด่านมีไว้กัน `NOT EXISTS`
ในคำสั่งเดียวปิดช่องนั้น (code review รอบ #31 เป็นคนเจอ) ถ้าไม่มีอะไรถูกลบ route จึงถามอีกครั้ง
เพื่อแยกสองเหตุ: กิจกรรมยังอ้างอยู่ → ปฏิเสธพร้อมเลขสัปดาห์ · แถวหายไปแล้วใต้มือ → `ไม่พบ`

**ไม่มีใครถูกบันทึกว่าแก้อะไร** — `created_by` มีและถูกเขียนตอน insert แต่ไม่มี `updated_by`
คำถาม "ใครย้ายสัปดาห์ 5" จึงไม่มีคำตอบ และหน้าจอไม่วาดบรรทัดผู้แก้

## ตั้งต้น

```
docker start deep-core-postgres
cd db      && npm run reset && npm run migrate && npm run seed
cd backend && npm start          # http://localhost:3000
cd frontend && npm start         # http://localhost:5000
```

**ต้อง reset + seed ใหม่จริง ๆ ก่อนเดินใบนี้ และต้อง kill แล้ว start backend ใหม่** —
`node server.js` ไม่มี reload ตรวจด้วยการ login แล้วยิง `GET /api/teaching/sections/1/plan`
หนึ่งครั้ง ต้องได้ 200 พร้อมสามสัปดาห์

ทุกบัญชีใน seed ใช้รหัสผ่านเดียวกัน คือ `deep-core-local`

ทางเข้า: เลือกตอนเรียนจากหน้า *รายวิชา* → เมนู **แผนการสอน** ที่อยู่ที่ได้คือ
`/teacher/teacherDashboard/<section_id>/teachingPlan`

seed ให้ทุกตอนเรียนทุกปี: สัปดาห์ **1 · 2 · 3** โดยสัปดาห์ 1 มีทั้งรายละเอียดและหมายเหตุ
สัปดาห์ 2 มีแต่รายละเอียด สัปดาห์ 3 ไม่มีทั้งคู่ — และ**สอบกลางภาค**อ้างสัปดาห์ 1 อยู่

| `section_id` (ที่อยู่) | ปีการศึกษา | ผู้สอน | ใช้เดินอะไร |
|---|---|---|---|
