## ข้อบกพร่อง

คำปฏิเสธของการเขียนที่ค้างอยู่ตอนเปิดหน้าต่าง (คำถามยืนยันถูกปิดระหว่างการเขียนค้าง #204 #217) ลงใน `notice` ขณะแบนเนอร์ไม่ถูกวาด ·
เมื่อการบันทึกของหน้าต่างสำเร็จ `load` พูดประโยคที่รออยู่ด้วย `setNotice(said)` ซึ่งเขียนทับคำปฏิเสธที่ยังไม่มีใครอ่าน ·
แถวที่บันทึกอยู่ในรายการให้ใครก็เห็น ส่วนคำปฏิเสธไม่อยู่ที่ไหนอีก จึงเป็นคำปฏิเสธที่ชนะ

## การแก้

`setNotice(shown => (shown?.error ? shown : said))` ที่จุดพูดของ `load` ในแต่ละจอ (ลอกไม่ได้ใช้ร่วม #83) · ประโยคอ่านออกจาก ref
**ก่อน** updater เพราะ `finally` ของ `load` ล้าง ref ก่อน React เรียก updater · คำปฏิเสธที่อยู่ใน `notice` ตอนหน้าต่างปิดเป็นคำที่ยังไม่มีใครอ่าน
เสมอ เพราะทุกตัวที่เปิดฟอร์มล้าง `notice` ก่อน (`setNotice(null)`) — กฎนี้จึงไม่เก็บคำปฏิเสธที่อ่านไปแล้ว
