# ตรวจรับ — #273 ปุ่มของจอฝั่งอาจารย์เป็น `RowAction`

[#273](https://github.com/khthana/Deep-QA/issues/273) — #271 ให้ปุ่มของจอผู้ดูแลผ่าน `RowAction.js` แต่จอฝั่ง
อาจารย์ยังวาดปุ่ม Heroicons เปล่าของตัวเอง ไม่มีกรอบ ไม่มี tooltip ขณะที่จอที่ส่งมอบ (`BT.js`) ใช้ไอคอนกรอบสี
ชุดเดียวกับผู้ดูแล **คำตอบของเจ้าของงาน 12 พ.ย. 2569: ก.** — คงการ์ดและชื่อของปุ่มไว้ ให้ tooltip เป็น**ชื่อเต็ม**
(ค่าปริยายของ `RowAction` เมื่อไม่มีใครส่ง `title`) และบนจอหลักฐาน **ตาในกลุ่มปุ่ม** แทนชื่อแฟ้มที่กดได้

**ประชากรวัดตอนลงมือ ไม่ใช่นับตามตั๋ว** (12 พ.ย. 2569): ตั๋วเขียนแปดจอ grep `HiOutlineTrash` กับ `HiOutlinePencil`
ได้สิบแฟ้ม ยี่สิบสามปุ่ม — อีกสองแฟ้มคือ `components/improvement/EntrySection.js` และแถวผลการเรียนรู้ใน
`components/activity/ActivityForm.js` ซึ่งจอคู่ที่ส่งมอบ (`ContinuousCard.js` · `AddNewActicity.js`) ใช้ไอคอน
ชุดเดียวกัน · `RowAction` รับ `to` เพิ่ม เพื่อให้ *หลักฐาน* ของ `LearningActivities` ยังเป็นลิงก์ และชื่อ tooltip
กับไอคอนเขียนที่เดียวสำหรับทั้งสองแท็ก · ปุ่มถังขยะของ `SubjectStudents.js` เป็นของใบ `271` แล้ว

## รายการที่ต้องเดิน

ช่องสุดท้ายมีสี่ค่า

- **☑** เดินด้วยมือจบแล้ว หรือพิสูจน์ที่ seam HTTP แล้ว — **สองอย่างนี้เป็น ☑ เท่ากัน** ⚙ สงวนไว้ให้ browser seam เท่านั้น และแถวบอกเองว่าอะไรพิสูจน์มัน (`CLAUDE.md` §Marks on the sheets · [#194](https://github.com/khthana/Deep-QA/issues/194))
- **◐** เดินไปได้ครึ่งเดียว อีกครึ่งยังไม่ได้เดิน — **แถวนั้นบอกไว้เองว่าครึ่งไหนยังขาด และครึ่งนั้นรออะไร** · ส่วนใหญ่ครึ่งที่เดินแล้วคือครึ่งของ server และครึ่งที่เหลือคือสิ่งที่หน้าจอวาด (แถบสี ตาราง dropdown) ซึ่งยังต้องมีคนดู — **แต่นั่นเป็นกรณีที่พบบ่อย ไม่ใช่นิยาม** ครึ่งที่เหลือรออยู่สามอย่าง คือ **คน** (เช่น attribute ที่ไปถึง DOM แล้ว แต่ยังไม่มีใครเปิดโปรแกรมอ่านหน้าจอฟัง) · **ตั๋ว** ซึ่งแถวจะอ้างเลขไว้ · หรือ **ไม่รออะไรเลย** เพราะไม่มีตัวควบคุมบนจอสร้างคำขอนั้นได้ ซึ่งเป็น ◐ ถาวรโดยโครงสร้าง — **สามอย่างนี้นับแยกกัน** (`CLAUDE.md` §Marks on the sheets · [#157](https://github.com/khthana/Deep-QA/issues/157))
- **☐** ยังไม่ได้เดิน
- **⚙** ครอบคลุมด้วย browser seam แล้ว (#65) ไม่ต้องเดินด้วยมือซ้ำ แถวบอกไฟล์ที่ครอบคลุมไว้ และมาร์กนี้ได้มาเมื่อมัตแตนต์ฆ่า assertion ของแถวนั้นเอง — **ถ้าแถวนั้นพูดถึงสิ่งที่วาดด้วย (เมนู ถ้อยคำ สี) ครึ่งนั้นยังเป็นงานของคนเดิน และแถวจะเขียนกำกับไว้** (`CLAUDE.md` §Two test seams · [#194](https://github.com/khthana/Deep-QA/issues/194))

ข้ออ้างที่ถามทุกปุ่มคือข้ออ้างของ `271a` โดยคำถูกแทนด้วยชื่อของปุ่มเอง: tooltip เท่าชื่อที่อ่านออกเสียงได้
ไม่มีคำบนหน้าปุ่ม และมีไอคอนเดียว ปุ่มเปล่าเดิมผ่านสองข้อหลังอยู่แล้ว จอที่ยังวาดปุ่มของตัวเองจึงตกที่ tooltip
มัตแตนต์อยู่ที่ `mutation/273-teacher-row-actions.py` หนึ่งตัวต่อปุ่ม (#125, #88) และกวาดเมื่อ 12 พ.ย. 2569
ยี่สิบหกของยี่สิบหกตรงตารางที่เขียนก่อน (รีวิวเพิ่มตัวที่ยี่สิบเจ็ดและรันห้าตัวซ้ำ บันทึกในแฟ้มมัตแตนต์) — รวมสี่ตัวของ `271-action-icons.py` ที่ตอนนี้เอื้อมถึงจอฝั่งอาจารย์ด้วย:
`wordsdrawn` `notitle` `noicon` ฆ่าทั้งสิบแถวของ `273a` และ `reasonlost` รอดทั้งสิบ เพราะไม่มีผู้เรียกฝั่งอาจารย์
