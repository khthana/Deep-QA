# ตรวจรับ — #291 เดินมือฟอร์มที่เหลือเทียบกับกฎ layout ของฟอร์ม

[#291](https://github.com/khthana/Deep-QA/issues/291) — กฎห้าข้อของ `docs/ui-form-layout.md` (คำตอบของเจ้าของงาน 19 พ.ย. 2569)
ลงในห้าฟอร์มที่มีช่อง *สถานะ* ด้วย #290 ใบนี้ถามฟอร์มที่เหลือทีละกฎ **ไม่แก้โค้ด** — เจ้าของงานเดิน แล้วตัดสินว่าจอไหนเปิดตั๋วแก้
และช่องแบบใหม่ที่ห้ากฎไม่ครอบคลุม (วันที่ ตัวเลข รหัสผ่าน ไฟล์ แถวในตาราง) ได้กฎข้อไหนเพิ่มในเอกสารนั้น

**ประชากรนับด้วยกลไก ไม่ใช่ด้วยรายชื่อในตั๋ว** (19 พ.ย. 2569): ไฟล์ที่ git track ใต้ `frontend/src` ที่ถือ `<form` มี 25 ไฟล์
ลบห้าฟอร์มของ #290 เหลือ **20** — รายชื่อแปดไฟล์ในตั๋วเป็น grep ของ `md:grid-cols-*` ซึ่งมองไม่เห็นฟอร์มที่จัดด้วย `sm:grid-cols-*`
ด้วย `space-y-*` หรือที่อยู่ในแถวของตาราง (#111, #174) · `RubricForm.js` และ `SelectApp.js` ที่ตั๋วถามถึงเป็นไฟล์ที่ไม่ได้ track
ในต้นไม้ทำงาน `RubricForm.js` ถูกเอาออกจากต้นไม้ใน #276 (`aefe44c`) และไม่มีไฟล์ไหน import ทั้งสอง จึงไม่อยู่ในประชากร
— วันที่ไฟล์ไหนถูก track หรือถูก mount ข้อนี้ต้องนับใหม่ · `GrantsPanel.js` `StudentGroups.js` ในตั๋วอยู่ในประชากรนี้

ยี่สิบไฟล์แบ่งเป็นสองกลุ่ม:

- **สิบสามฟอร์มบนสิบเอ็ดหน้า (`Users.js` และ `Offerings.js` ถือหน้าละสองฟอร์ม) ที่มีช่องแบบที่ห้ากฎพูดถึง** (ชื่อ รหัส ตัวเลขสั้น dropdown) — เดินทีละกฎ หัวข้อละจอข้างล่าง
- **เจ็ดฟอร์มที่รูปไม่ใช่ฟอร์มข้อมูล** — ถามเจ้าของงานว่าอยู่นอกกฎหรือไม่ ท้ายใบ (§นอกรูปของห้ากฎ)

คอลัมน์ *ต้องเห็นอะไร* บอก **สิ่งที่กฎขอ** และ **สิ่งที่โค้ดวาดวันนี้ตามที่อ่านจาก JSX** (ไม่ใช่การวัด) ให้เจ้าของงานดูว่าสองอย่างตรงกันไหม
และบอกในแถวว่า *ตรงกฎ* · *ไม่ตรง — เปิดตั๋ว* · หรือ *กฎไม่ครอบคลุม — กฎใหม่คือ …* ไม่มีแถว ⚙ เพราะเป็นรูปลักษณ์

## รายการที่ต้องเดิน

ช่องสุดท้ายมีสี่ค่า

- **☑** เดินด้วยมือจบแล้ว หรือพิสูจน์ที่ seam HTTP แล้ว — **สองอย่างนี้เป็น ☑ เท่ากัน** ⚙ สงวนไว้ให้ browser seam เท่านั้น และแถวบอกเองว่าอะไรพิสูจน์มัน (`CLAUDE.md` §Marks on the sheets · [#194](https://github.com/khthana/Deep-QA/issues/194))
- **◐** เดินไปได้ครึ่งเดียว อีกครึ่งยังไม่ได้เดิน — **แถวนั้นบอกไว้เองว่าครึ่งไหนยังขาด และครึ่งนั้นรออะไร** · ส่วนใหญ่ครึ่งที่เดินแล้วคือครึ่งของ server และครึ่งที่เหลือคือสิ่งที่หน้าจอวาด (แถบสี ตาราง dropdown) ซึ่งยังต้องมีคนดู — **แต่นั่นเป็นกรณีที่พบบ่อย ไม่ใช่นิยาม** ครึ่งที่เหลือรออยู่สามอย่าง คือ **คน** (เช่น attribute ที่ไปถึง DOM แล้ว แต่ยังไม่มีใครเปิดโปรแกรมอ่านหน้าจอฟัง) · **ตั๋ว** ซึ่งแถวจะอ้างเลขไว้ · หรือ **ไม่รออะไรเลย** เพราะไม่มีตัวควบคุมบนจอสร้างคำขอนั้นได้ ซึ่งเป็น ◐ ถาวรโดยโครงสร้าง — **สามอย่างนี้นับแยกกัน** (`CLAUDE.md` §Marks on the sheets · [#157](https://github.com/khthana/Deep-QA/issues/157))
- **☐** ยังไม่ได้เดิน
- **⚙** ครอบคลุมด้วย browser seam แล้ว (#65) ไม่ต้องเดินด้วยมือซ้ำ แถวบอกไฟล์ที่ครอบคลุมไว้ และมาร์กนี้ได้มาเมื่อมัตแตนต์ฆ่า assertion ของแถวนั้นเอง — **ถ้าแถวนั้นพูดถึงสิ่งที่วาดด้วย (เมนู ถ้อยคำ สี) ครึ่งนั้นยังเป็นงานของคนเดิน และแถวจะเขียนกำกับไว้** (`CLAUDE.md` §Two test seams · [#194](https://github.com/khthana/Deep-QA/issues/194))

## หลังเดิน

คืนค่าทั้งสี่ระเบียนของ §ตั้งต้น แล้วเจ้าของงานตัดสินสองอย่าง (ตั๋วข้อสาม):

- จอไหนเปิดตั๋วแก้ — ตั๋วละกลุ่มที่แก้ด้วยกลไกเดียวกัน ไม่ใช่ตั๋วละจอ เว้นแต่เจ้าของงานเลือกอย่างอื่น
- ช่องแบบใหม่ได้กฎข้อไหนเพิ่มใน `docs/ui-form-layout.md` — ที่ใบนี้พบ: ชื่อ–นามสกุลคู่กัน · คำนำหน้า · วันที่ · รหัสผ่าน · textarea คู่กัน · ช่องไฟล์ ·
  แถวกรอกในตาราง · ฟอร์มสั้นในแถบ · จุดเริ่มเคียงกันที่ `sm` (640) แทน `md` (768)
