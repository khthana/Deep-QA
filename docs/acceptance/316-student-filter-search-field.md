# ตรวจรับ — #316 ช่องกรองนักศึกษาในแผงข้างหน้าตาเป็นช่องค้นหา

[#316](https://github.com/khthana/Deep-QA/issues/316) — `docs/ui-consistency.md` ข้อ 7 (คำตอบของเจ้าของงาน 27 พ.ย. 2569)
ช่องกรองรายชื่อนักศึกษาในแผงข้างของ *ผลการเรียนของนักศึกษา* (`StudentResults.js`) และ *ผลระดับหลักสูตรรายบุคคล*
(`ProgramLevelIndividual.js`) วาดผ่าน `SearchField` ใน `frontend/src/components/SearchBox.js` — หน้าตาของ `SearchBox`
(แว่นขยาย พื้น `bg-gray-50` กรอบ `ring-blue-500` เมื่อกด) แยกออกจากสิ่งที่มันทำ · `SearchBox` เองวาดผ่านมันด้วย class เดิมทุกตัว

## สิ่งที่ตั๋วไม่ได้เขียน และวัดได้ตอนลงมือ (27 พ.ย. 2569)

- **สองช่องเป็น `type="search"` แล้ว** จึงมีบทบาท `searchbox` อย่างช่องค้นหาทุกช่อง — ชื่อที่เข้าถึงได้คงเป็น
  *ค้นหานักศึกษาด้วยรหัสหรือชื่อ* และ `e2e/support/program-student-screen.js` หามันด้วย `getByLabel` ซึ่งไม่ถามบทบาท
  ไม่มี spec ใดหาสองช่องนี้ด้วย `textbox` (grep 27 พ.ย. 2569) · Chromium วาดปุ่มล้างในช่อง `search` ซึ่งยิง `onChange`
  ด้วยค่าว่าง รายชื่อจึงกลับเต็มอย่างการลบด้วยมือ
- **ไม่มีมัตแตนต์ใหม่** — สิ่งที่เปลี่ยนเป็นหน้าตาล้วน (CLAUDE.md §Two test seams) · การกรองขณะพิมพ์ไม่ได้แตะ:
  `value={term}` กับ `setTerm` ทุกครั้งที่พิมพ์ ย้ายจาก `<input>` ไปเป็น prop ทั้งสองบรรทัด · มัตแตนต์ของ `SearchBox`
  (`s272boxforgets` · `s272boxsame`) ยึดบรรทัดตรรกะที่ไม่ได้ขยับ และ `python mutation/anchors.py` ผ่าน

## รายการที่ต้องเดิน

ช่องสุดท้ายมีสี่ค่า

- **☑** เดินด้วยมือจบแล้ว หรือพิสูจน์ที่ seam HTTP แล้ว — **สองอย่างนี้เป็น ☑ เท่ากัน** ⚙ สงวนไว้ให้ browser seam เท่านั้น และแถวบอกเองว่าอะไรพิสูจน์มัน (`CLAUDE.md` §Marks on the sheets · [#194](https://github.com/khthana/Deep-QA/issues/194))
- **◐** เดินไปได้ครึ่งเดียว อีกครึ่งยังไม่ได้เดิน — **แถวนั้นบอกไว้เองว่าครึ่งไหนยังขาด และครึ่งนั้นรออะไร** · ส่วนใหญ่ครึ่งที่เดินแล้วคือครึ่งของ server และครึ่งที่เหลือคือสิ่งที่หน้าจอวาด (แถบสี ตาราง dropdown) ซึ่งยังต้องมีคนดู — **แต่นั่นเป็นกรณีที่พบบ่อย ไม่ใช่นิยาม** ครึ่งที่เหลือรออยู่สามอย่าง คือ **คน** (เช่น attribute ที่ไปถึง DOM แล้ว แต่ยังไม่มีใครเปิดโปรแกรมอ่านหน้าจอฟัง) · **ตั๋ว** ซึ่งแถวจะอ้างเลขไว้ · หรือ **ไม่รออะไรเลย** เพราะไม่มีตัวควบคุมบนจอสร้างคำขอนั้นได้ ซึ่งเป็น ◐ ถาวรโดยโครงสร้าง — **สามอย่างนี้นับแยกกัน** (`CLAUDE.md` §Marks on the sheets · [#157](https://github.com/khthana/Deep-QA/issues/157))
- **☐** ยังไม่ได้เดิน
- **⚙** ครอบคลุมด้วย browser seam แล้ว (#65) ไม่ต้องเดินด้วยมือซ้ำ แถวบอกไฟล์ที่ครอบคลุมไว้ และมาร์กนี้ได้มาเมื่อมัตแตนต์ฆ่า assertion ของแถวนั้นเอง — **ถ้าแถวนั้นพูดถึงสิ่งที่วาดด้วย (เมนู ถ้อยคำ สี) ครึ่งนั้นยังเป็นงานของคนเดิน และแถวจะเขียนกำกับไว้** (`CLAUDE.md` §Two test seams · [#194](https://github.com/khthana/Deep-QA/issues/194))
