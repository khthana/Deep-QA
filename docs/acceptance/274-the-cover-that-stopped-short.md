# ตรวจรับ — #274 ผ้าคลุมของหน้าต่างหยุดก่อนถึงขอบบน 24 px

[#274](https://github.com/khthana/Deep-QA/issues/274) — ผ้าคลุม `fixed inset-0` ของ `ConfirmDialog` กับ
`ImportPanel` ถูก mount อยู่ใน `<div className="space-y-6">` ของหน้า Tailwind 3 เขียน `space-y-6` เป็น
`.space-y-6 > :not([hidden]) ~ :not([hidden])` ผ้าคลุมจึงได้ `margin-top: 24px` และเริ่มที่ `top: 24`
โลโก้ (ลิงก์) กับปุ่มโปรไฟล์ในแถบนั้นกดได้ทั้งที่หน้าต่างเปิดอยู่ พบตอนเดินใบ `270` แถว 11 เมื่อ 12 พ.ย. 2569
และ `ConfirmDialog` เป็นรูปนี้มาก่อน #270

การแก้คือ `!m-0` ที่ผ้าคลุมของทั้งสองคอมโพเนนต์ — `mt-0` ธรรมดาเป็น `0,1,0` แพ้ `0,3,0` ของตัวเลือกพี่น้อง (`:not([hidden])` แต่ละตัวนับเป็นหนึ่งแอตทริบิวต์)
ทางเลือกอีกทางในตั๋วคือ portal ไปที่ `document.body` ซึ่งย้ายทั้งต้นไม้ของหน้าต่างและไม่ได้ซื้ออะไรเพิ่มที่วัดได้

**ประชากรนับด้วยกลไก ไม่ใช่ด้วยชื่อคอมโพเนนต์** (12 พ.ย. 2569): `fixed inset-0` ใน `frontend/src` มีสี่ที่ อีกสองที่ไม่ได้อยู่
ใน `space-y-*` — `SessionExpiredDialog` ถูก mount ใน `<div className="font-thai">` ของ `App.js` เป็นพี่น้องของ
`<AppRoutes />` และ `LoadingScreen` เป็นสิ่งเดียวที่ guard ใน `routes/AppRoutes.js` คืนออกมา ทั้งสองจึงไม่มีตัวเลือกพี่น้อง
ให้ margin วันที่คอมโพเนนต์ไหนในสองตัวนี้ถูกย้ายเข้าไปในหน้า ข้อนี้ต้องวัดใหม่

grep นั้นมองไม่เห็นผ้าคลุมที่เขียน `fixed left-0 top-0 h-screen w-screen` อีกสองผืน — กล่องเปลี่ยนรหัสผ่านของ
`Navbar.js` กับ `ProfilePhotoDialog.js` — ซึ่งรีวิวพบ ทั้งคู่อยู่ในแถบบน `fixed … backdrop-blur-md` ของ `Mainpage.js`
และบรรพบุรุษที่มี `backdrop-filter` เป็น containing block ของลูกที่ `fixed` **วัดเมื่อ 12 พ.ย. 2569** บน Docker
(`dept.admin.05@`, viewport 1536×770): ผ้าคลุมทั้งสองผืนเป็นลูกของแถบจริง และกรอบเป็น `0,0,1536,770` ทั้งคู่ การกดที่มุม
ทั้งสี่ กลางจอ และที่ `x = 100` กับขอบขวาของ `y = 10` ตกบนผ้าคลุมทุกจุด — แถบเริ่มที่ `0,0` และ `h-screen w-screen`
เป็นหน่วยของ viewport ซึ่ง containing block ไม่เปลี่ยน จึงเป็นเรื่องบังเอิญของตำแหน่งแถบ ไม่ใช่ข้อบกพร่อง วันที่แถบ
ไม่ได้เริ่มที่ `0,0` ข้อนี้ต้องวัดใหม่

- **☐** ยังไม่ได้เดิน
- **⚙** ครอบคลุมด้วย browser seam แล้ว (#65) ไม่ต้องเดินด้วยมือซ้ำ แถวบอกไฟล์ที่ครอบคลุมไว้ และมาร์กนี้ได้มาเมื่อมัตแตนต์ฆ่า assertion ของแถวนั้นเอง — **ถ้าแถวนั้นพูดถึงสิ่งที่วาดด้วย (เมนู ถ้อยคำ สี) ครึ่งนั้นยังเป็นงานของคนเดิน และแถวจะเขียนกำกับไว้** (`CLAUDE.md` §Two test seams · [#194](https://github.com/khthana/Deep-QA/issues/194))
