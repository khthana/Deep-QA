## ตั้งต้น

```
docker start deep-core-postgres
cd db      && npm run reset && npm run migrate && npm run seed
cd backend && npm start          # http://localhost:3000
cd frontend && npm start         # http://localhost:5000
```

ทุกบัญชีใน seed ใช้รหัสผ่านเดียวกัน คือค่า `PASSWORD` ใน `db/seed.js`
เมนูที่ใช้ตลอดเอกสารนี้คือ *ข้อมูลหลัก → ข้อมูลรายวิชา* (`/main/subjects`)

seed มีรายวิชาเดียวคือ `01076105` *การเขียนโปรแกรมเชิงวัตถุ* 3 หน่วยกิต อยู่ในภาควิชา `05`
และ **มีข้อมูลอ้างอิงอยู่** (รายวิชาในหลักสูตร → การเปิดสอน → CLO → คะแนน) รายวิชาที่จะลบได้จริง
จึงต้องสร้างเองในข้อ 1 ส่วนภาควิชา `01` ยังไม่มีรายวิชาเลย และ `dept.admin.01@` เป็นผู้ดูแลของ
ภาควิชานั้น — สองอย่างนี้คือคู่ที่ใช้เดินข้อ 3

**รหัสวิชายาวได้ไม่เกิน 8 ตัวอักษร** เพราะคอลัมน์เป็น `varchar(8)` และรหัสวิชาจริงของ KMITL
มีแปดหลักพอดี ตัวอย่างที่ใช้ข้างล่างจึงเป็นแปดหลักทั้งหมด

ไฟล์ CSV ที่ข้อ 6 และข้อ 7 ใช้ ถูกเตรียมไว้ให้แล้วในโฟลเดอร์ Downloads ทั้งสี่ไฟล์ —
`subjects-good.csv`, `subjects-broken.csv`, `subjects-no-description.csv`, `subjects-many.csv`
บันทึกเป็น UTF-8 พร้อม BOM แบบเดียวกับที่ Excel เขียน จึงไม่ต้องแก้ไฟล์ด้วยมือ ซึ่งเป็นที่มา
ของปัญหา encoding ตอนเดิน #15

หลายข้อข้างล่างเขียนข้อมูลจริงลงฐานข้อมูล — **`npm run seed` ใหม่หลังเดินจบ** ก่อนเริ่มตั๋วถัดไป
