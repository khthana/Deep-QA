# ตรวจรับ — #317 ปุ่มกลับเป็นปุ่มกรอบเทามีลูกศร

[#317](https://github.com/khthana/Deep-QA/issues/317) — `docs/ui-consistency.md` ข้อ 9 (คำตอบของเจ้าของงาน 27 พ.ย. 2569)
หน้าตาของปุ่มกลับอยู่ที่ `frontend/src/components/BackButton.js` ที่เดียว: class `BACK_BUTTON` (กรอบเทา แบบปุ่ม
*กลับไปหน้ารายการ* ของแผงกลุ่มเรียน) กับลูกศร `BackArrow` (`HiOutlineArrowLeft` แบบ `aria-hidden`) · สี่จุดใช้ทั้งคู่ —
`RubricCriteria.js` สองจุด (ใต้คำปฏิเสธ และบนหัวหน้า) · `TeacherSection.js` · `components/offerings/SectionsPanel.js`

## สิ่งที่ตั๋วไม่ได้เขียน และวัดได้ตอนลงมือ (27 พ.ย. 2569)

- **ทำเป็น class กับลูกศร ไม่ได้ทำเป็นคอมโพเนนต์** — ลิงก์ของ rubric ยังเป็น `<Link>` ส่วนปุ่มของอาจารย์และแผงกลุ่มเรียนยังเป็น
  `<button>` ตามเกณฑ์ข้อ 2 · ทุก spec หาสี่จุดนี้ด้วยบทบาทและคำ (`23a` `24a` `116a` `139a` `140a` `141a` `142a` `203a` `249a`
  `266a` และ `e2e/support/offerings-screen.js`) ลูกศรไม่มีชื่อ จึงไม่น่าจะเปลี่ยนอะไรให้พวกมัน — แต่ยังไม่รัน
- **อีกสามหน้ามีลูกศรนำหน้าลิงก์อยู่แล้ว และไม่อยู่ในตั๋วนี้** — *ผลการเรียนรู้รายวิชา* บนหัวของ `MeasurableBehaviors.js`
  `AchievementCriteria.js` และ `ActivityEvidence.js` เป็นคำสีน้ำเงินมี `HiOutlineArrowLeft` พาขึ้นไปหน้า CLO ·
  ข้อ 9 ระบุ *ทั้งสามจุด* และไม่ได้นับสามลิงก์นี้ จึงเป็นคำถามถึงเจ้าของงาน ไม่ใช่งาน — ส่งไปที่
  [#335](https://github.com/khthana/Deep-QA/issues/335)
- **ไม่มีมัตแตนต์ใหม่** — สิ่งที่เปลี่ยนเป็นหน้าตาล้วน (CLAUDE.md §Two test seams) · ปลายทางของทั้งสี่จุดไม่ได้แตะ และ
  `python mutation/anchors.py` ผ่าน — ไม่มีมัตแตนต์ใดยึดบรรทัดที่เปลี่ยน

## รายการที่ต้องเดิน

ช่องสุดท้ายมีสี่ค่า

- **☑** เดินด้วยมือจบแล้ว หรือพิสูจน์ที่ seam HTTP แล้ว — **สองอย่างนี้เป็น ☑ เท่ากัน** ⚙ สงวนไว้ให้ browser seam เท่านั้น และแถวบอกเองว่าอะไรพิสูจน์มัน (`CLAUDE.md` §Marks on the sheets · [#194](https://github.com/khthana/Deep-QA/issues/194))
- **◐** เดินไปได้ครึ่งเดียว อีกครึ่งยังไม่ได้เดิน — **แถวนั้นบอกไว้เองว่าครึ่งไหนยังขาด และครึ่งนั้นรออะไร** · ส่วนใหญ่ครึ่งที่เดินแล้วคือครึ่งของ server และครึ่งที่เหลือคือสิ่งที่หน้าจอวาด (แถบสี ตาราง dropdown) ซึ่งยังต้องมีคนดู — **แต่นั่นเป็นกรณีที่พบบ่อย ไม่ใช่นิยาม** ครึ่งที่เหลือรออยู่สามอย่าง คือ **คน** (เช่น attribute ที่ไปถึง DOM แล้ว แต่ยังไม่มีใครเปิดโปรแกรมอ่านหน้าจอฟัง) · **ตั๋ว** ซึ่งแถวจะอ้างเลขไว้ · หรือ **ไม่รออะไรเลย** เพราะไม่มีตัวควบคุมบนจอสร้างคำขอนั้นได้ ซึ่งเป็น ◐ ถาวรโดยโครงสร้าง — **สามอย่างนี้นับแยกกัน** (`CLAUDE.md` §Marks on the sheets · [#157](https://github.com/khthana/Deep-QA/issues/157))
- **☐** ยังไม่ได้เดิน
- **⚙** ครอบคลุมด้วย browser seam แล้ว (#65) ไม่ต้องเดินด้วยมือซ้ำ แถวบอกไฟล์ที่ครอบคลุมไว้ และมาร์กนี้ได้มาเมื่อมัตแตนต์ฆ่า assertion ของแถวนั้นเอง — **ถ้าแถวนั้นพูดถึงสิ่งที่วาดด้วย (เมนู ถ้อยคำ สี) ครึ่งนั้นยังเป็นงานของคนเดิน และแถวจะเขียนกำกับไว้** (`CLAUDE.md` §Two test seams · [#194](https://github.com/khthana/Deep-QA/issues/194))
