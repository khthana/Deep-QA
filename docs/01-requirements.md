## 1. วัตถุประสงค์ของระบบ (§1.2)

| # | วัตถุประสงค์ |
|---|---|
| OBJ-1 | พัฒนาเว็บแอปพลิเคชันแบบรวมศูนย์ที่รองรับผู้ใช้งานหลายบทบาทพร้อมกัน พร้อมระบบยืนยันตัวตนและการกำหนดสิทธิ์ (Authentication + RBAC) |
| OBJ-2 | รองรับการกำหนด เชื่อมโยง และติดตามผลการเรียนรู้ระดับหลักสูตร (PLO) และระดับรายวิชา (CLO) ในโครงสร้างเชิงลำดับชั้น พร้อมประเมินการบรรลุผลทั้งระดับรายวิชาและระดับหลักสูตร |
| OBJ-3 | ลดความซ้ำซ้อนและข้อผิดพลาดของข้อมูล ด้วยการนำเข้าข้อมูลผ่าน Excel Template ที่มีการตรวจสอบความถูกต้องอัตโนมัติ และการแสดงผลเชิงวิเคราะห์ |
| OBJ-4 | สนับสนุนงานประกันคุณภาพตามเกณฑ์ TABEE ด้วยรายงานผลการบรรลุผลการเรียนรู้และการเปรียบเทียบข้ามปีการศึกษา |

## 2. ขอบเขตของระบบ (§1.3)

| # | ขอบเขต |
|---|---|
| SC-1 | ระบบจัดการผู้ใช้งานและสิทธิ์ (User & Permission Management) |
| SC-2 | ระบบจัดการข้อมูลหลักและโครงสร้าง (Master Data & Structure — ภาควิชา / หลักสูตร / รายวิชา / Rubric กลาง / การเปิดรายวิชา) |
| SC-3 | ระบบจัดการผลการเรียนรู้และการประเมิน (PLO / CLO / Mapping / เกณฑ์การประเมิน) |
| SC-4 | ระบบจัดการนักศึกษาและข้อมูลการเรียน (รายชื่อ / กลุ่มงาน / กิจกรรม / คะแนน / หลักฐาน) |
| SC-5 | ระบบประเมินผลและแสดงผลการบรรลุผลการเรียนรู้ (Radar / Heatmap / Sankey / รายงาน PDF) |

## 3. ประโยชน์ที่คาดว่าจะได้รับ (§1.4)

1. มีระบบกลางเก็บข้อมูลหลักสูตรและผลการเรียนรู้ที่เป็นมาตรฐานเดียวกัน
2. ลดภาระงานเอกสารและความซ้ำซ้อนของการกรอกข้อมูลของอาจารย์และกรรมการหลักสูตร
3. เห็นภาพการบรรลุผลการเรียนรู้ทั้งระดับบุคคล รายวิชา และหลักสูตร ได้ทันที
4. ใช้เป็นหลักฐานประกอบการรับรองมาตรฐานคุณภาพ TABEE ได้โดยตรง

## 4. บทบาทผู้ใช้งาน (§3.2 ตาราง 3.1)

| Role ID | บทบาท | ขอบเขตสิทธิ์ |
|---|---|---|
| ROLE-1 | ผู้ดูแลระบบกลาง (Central Admin / FULL_ADMIN) | สิทธิ์สูงสุดในระบบจัดการผู้ใช้งานและสิทธิ์ |
| ROLE-2 | ผู้ดูแลระดับคณะ (Faculty Admin) | จัดการผู้ใช้/สิทธิ์, ข้อมูลหลักและโครงสร้าง (ยกเว้นการเปิดรายวิชา), ผลการเรียนรู้ — ในขอบเขตคณะ |
| ROLE-3 | ผู้ดูแลระดับภาควิชา (Department Admin) | สิทธิ์เดียวกับ ROLE-2 แต่จำกัดขอบเขตเฉพาะภาควิชาตนเอง |
| ROLE-4 | กรรมการหลักสูตร (Curriculum Committee) | เฉพาะหลักสูตรของตนเอง: ข้อมูลหลัก (ยกเว้นข้อมูลภาควิชา/หลักสูตร/รายวิชา), ผลการเรียนรู้, การเปิดรายวิชา, การประเมินและแสดงผลการบรรลุผล |
| ROLE-5 | อาจารย์ / ผู้สอน (Teacher) | จัดการนักศึกษาและข้อมูลการเรียนในรายวิชาที่ตนสอน |
| ROLE-6 | ผู้ประเมินภายนอก (External Assessor) | บัญชีชั่วคราวที่มีช่วงเวลาการใช้งานกำหนดไว้ (ดู R005) |

> **กฎสำคัญ (R006):** สิทธิ์ที่มอบให้ต้องไม่เกินสิทธิ์ของผู้มอบ เช่น ผู้ดูแลระดับภาควิชาจะให้สิทธิ์สูงสุดได้แค่ระดับภาควิชาเท่านั้น
