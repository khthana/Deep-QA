# ชื่อของหน่วยงานบนหน้าจอ

กฎหกข้อนี้เป็นคำตอบของเจ้าของงานเมื่อ 20 พ.ย. 2569 (การซักของ #294) ต่อข้อสังเกตว่า หลายหน้ายังแสดงรหัสหน่วยงาน
เช่น `0501` หรือ `01` และบางหน้ามีแต่รหัส · ระบบนี้ใช้งานจริง การเปลี่ยนสิ่งที่หน้าจอวาดจึงเป็นคำถามของเจ้าของงาน
(`docs/06` §Out of Scope) และนี่คือคำตอบ · คำตอบนี้**กลับ**คำตอบสองข้อก่อนหน้า: 23 ต.ค. 2569 (#215) ที่ให้สองจอผู้ดูแล
เขียน `ชนิด · ชื่อ (รหัส)` และ 27 ต.ค. 2569 (#231) ที่ให้เมนูบทบาทเขียน `ชื่อ (รหัส)`

## กฎ

1. **ตัดเฉพาะรหัสหน่วยงาน** — คณะ ภาควิชา หลักสูตร (`ENG`, `05`, `01`, `0501`, `0503`) · รหัสรายวิชา
   รหัสนักศึกษา รหัสบัญชีผู้ใช้ และรหัส PLO **คงไว้** เพราะเป็นสิ่งที่คนใช้หาของจริง
2. **หน้าจัดการหลักสูตรและภาควิชา (`main/programs`, `main/departments`) ยังแสดงรหัส** — คอลัมน์ในตาราง ช่องในฟอร์ม
   และกล่องยืนยันลบ เพราะรหัสคือข้อมูลของเรคอร์ดนั้นเอง ที่ผู้ดูแลพิมพ์เข้าไป
3. **ที่อื่นทั้งหมดใช้ชื่อแทนรหัส และใส่คำบอกชนิดไว้ข้างหน้า** ถ้าบรรทัดนั้นยังไม่ได้บอกชนิด — เพราะภาควิชา `05` กับ
   หลักสูตร `0501` ชื่อ *วิศวกรรมคอมพิวเตอร์* ทั้งคู่ และ `01`/`0101` ชื่อ *วิศวกรรมโยธา* ทั้งคู่ (#90) · เจ้าของงาน
   ยอมรับว่าสองหลักสูตรที่ชื่อเหมือนกันทุกตัวอักษรจะแยกกันไม่ออก
4. **ตัดวงเล็บรหัสในปุ่มบทบาท รายการบทบาท และหน้าจัดการผู้ใช้**
5. **PDF ของการจับคู่ PLO กับรายวิชา:** หัวเอกสารตัดรหัส (`หลักสูตรวิศวกรรมคอมพิวเตอร์ (หลักสูตรปี 2564)`)
   แต่**ชื่อไฟล์คงรหัส** (`plo-mapping-0501.pdf`) เพราะชื่อไฟล์ต้องเป็นตัวอักษรที่ปลอดภัยและไม่ซ้ำ
6. **ถ้าหาชื่อไม่เจอ ใช้รหัส** — เช่นประวัติการใช้งานที่พูดถึงหลักสูตรที่ถูกลบไปแล้ว รหัสคือสิ่งเดียวที่เหลือที่บอกว่ามันคืออะไร · [#297](https://github.com/khthana/Deep-QA/issues/297) (20 พ.ย. 2569) ใช้กฎนี้กับภาควิชาหรือหลักสูตรที่ไม่มีชื่อไทยด้วย (`ภาควิชา 05`) และคอลัมน์ชื่อยังว่างได้

และข้อที่เจ็ดที่ตอบระหว่างลงมือ (20 พ.ย. 2569): ขอบเขตของบทบาทที่อยู่**นอกเอื้อม**ของผู้อ่าน — ที่เคยวาดเป็นรหัสเปล่า
เพราะชื่อมาจากรายการที่ผู้อ่านเสนอได้ — **server ส่งชื่อมากับบทบาท**

## คำบอกชนิดเขียนติดกับชื่อ ([#295](https://github.com/khthana/Deep-QA/issues/295), 20 พ.ย. 2569)

กฎข้อ 3 บอกว่า *ใส่คำบอกชนิดข้างหน้า* แต่ไม่ได้บอกว่าเชื่อมอย่างไร #294 จึงปิดโดยมีสามรูปอยู่ด้วยกัน — ` · ` คั่นในสาม
จอฝั่งผู้ดูแล ติดกันในจอที่เคยมีแต่รหัส และชื่อบทบาทเว้นวรรคแล้วติดกันในเมนูบทบาท · เจ้าของงานตอบวันเดียวกันว่า
**ทุกจอเขียนติดกัน** แบบหัว PDF ที่เขียนเป็นตัวอย่าง:

| ที่ | อ่านว่า |
|---|---|
| ช่องเลือกขอบเขต ตารางบทบาทที่ถือ | `ภาควิชาวิศวกรรมคอมพิวเตอร์` |
| คอลัมน์บทบาทของรายการบัญชี | `อาจารย์ผู้สอน (ภาควิชาวิศวกรรมโยธา)` |
| แผงกลุ่มเรียน กล่องยืนยันนำรายวิชาออก หัว PDF ประวัติการใช้งาน | `หลักสูตรวิศวกรรมคอมพิวเตอร์` |
| เมนูบทบาท ของบทบาทที่ชื่อไม่บอกชนิด | `ผู้ประเมินภายนอก หลักสูตรวิศวกรรมคอมพิวเตอร์` — ชื่อบทบาท เว้นวรรค แล้วรูปเดียวกัน |

ชื่อที่ขึ้นต้นด้วยคำบอกชนิดอยู่แล้ว (`คณะวิศวกรรมศาสตร์`) ขอบเขตที่ไม่ถูกจำกัด (`ทั้งมหาวิทยาลัย`) และบทบาทที่ชื่อบอกชนิด
(`กรรมการหลักสูตร วิศวกรรมคอมพิวเตอร์`) ไม่เติมคำซ้ำ

รหัสที่ใช้แทนชื่อที่หาไม่เจอ เว้นวรรคหลังคำบอกชนิดเสมอ (`หลักสูตร Z294GONE`) เพื่อไม่ให้คำกับรหัสติดกัน

## กลไก

- **ชื่อของขอบเขตของบทบาท** แปลที่ server ด้วย `backend/auth/scopeNames.js` ตามลำดับของ `scopeChain`
  (หลักสูตร → ภาควิชา → คณะ) ซึ่งสามการอ่านใช้ร่วม: `allRoles` (เมนูบทบาท) · `HELD` ของ `GET /users/:id/roles`
  (ตารางบทบาทที่ถือ) · `GRANTS` ของรายการบัญชี · หน้าจอเรียก `grantScope` ของ `scopeLabel.js` ซึ่งตกกลับไปหาใน
  รายการที่เสนอได้ (สำหรับ *ทั้งมหาวิทยาลัย* ซึ่งไม่อยู่ในสามตาราง) และตกกลับเป็นรหัส
- **ชื่อของเรคอร์ดในประวัติ** แปลที่ `backend/routes/history.js` §`TARGET_NAME` เฉพาะ `DEPARTMENT` และ `PROGRAM`
- **หน้าอื่น** ใช้ชื่อที่หน้านั้นถืออยู่แล้ว (รายการหลักสูตรของตัวกรอง) และตกกลับเป็นรหัส
- **census** `frontend/scripts/org-codes.js` แดงเมื่อหน้าจอวาด `program_id` `department_id` `faculty_id` หรือ `scope_id`
  เป็นลูกของ JSX หรือในประโยคไทย โดยไม่มีเครื่องหมาย `// org-code: <เหตุผล> (#NNN)` · การวาดเป็นทางตกกลับของชื่อ
  (ขวาของ `??` หรือ `||`) นับแยก ไม่แดง · สิ่งที่มันมองไม่เห็นอยู่ใน docblock ของมัน
- **ข้อความจาก server** census อ่านไม่ได้ จึงนับด้วยมือเมื่อ 20 พ.ย. 2569: ไม่มีคำปฏิเสธใน `backend/auth/refusals.js`
  ที่รับรหัสหน่วยงานเป็นพารามิเตอร์ และรหัสใน `routes/programSubjects.js` เป็นกุญแจของแถวที่ซ้ำ ไม่ใช่ประโยค ·
  วันที่ประโยคไหนของ server รับรหัสหน่วยงาน ข้อนี้ต้องนับใหม่
- **ช่องที่พิมพ์รหัสลงไป** — `รหัสภาควิชา` และ `รหัสหลักสูตร` ในฟอร์มบัญชีผู้ใช้ (`UserForm.js`) เป็นช่องกรอก ไม่ใช่สิ่งที่วาด
  ให้อ่าน กฎหกข้อไม่ได้พูดถึงช่องกรอก จึงยังเป็นคำถามของเจ้าของงาน (20 พ.ย. 2569) ไม่ได้แก้ใน #294
