## เรื่องที่จะกินเวลาถ้าไม่รู้ (gotchas)

- **โคลนอื่นยังมี `master` ที่ตายแล้ว** `git remote set-head origin -a && git branch -m master main
  && git branch --set-upstream-to=origin/main main`
- **`\uXXXX` ที่พิมพ์ลงคำสั่ง Bash ถูกถอดรหัสเป็นอักขระจริง** ก่อนถึง Python — สามรอบแรกของการ
  แพตช์ไฟล์นี้ล้มด้วยเหตุนี้ และตัวที่บอกคือ `cat -A` เห็นไบต์ไทยจริงในสคริปต์ที่สร้างออกมา
  วิธีที่ใช้ได้คือสร้างข้อความไทยจาก codepoint (`chr(...)`) หรือเฉือนออกจากไฟล์ของรีโปเอง
  และสร้าง backslash ด้วย `chr(92)`
- **`backend/test/users.test.js` เขียนภาษาไทยเป็น escape `\uXXXX`** ส่วน `refusals.js` กับ
  `Login.js` เขียนอักขระไทยจริง — อย่าสลับ
- **ห้าม `git add -A`** (ตัวจำแนกอ่านว่าเป็นการ stage `.env` จริง) stage เป็น path เสมอ
