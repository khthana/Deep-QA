## เรื่องที่จะกินเวลาถ้าไม่รู้ (gotchas)

- **clone อื่นยังมี `master` ที่ตายแล้ว** ปลายทางเปลี่ยนเป็น `main` แล้ว clone เก่าต้องแก้มือ:
  `git branch -m master main && git fetch origin && git branch -u origin/main main && git remote set-head origin -a`
- **`git add -A` ถูกปฏิเสธ** เพราะรีโปมี `DEEP-QA-BACKEND/` กับ `_local/` อยู่ข้างใน
  **stage ด้วยพาธชัดเจนเสมอ** และห้าม `git add` อะไรใต้สองที่นั้น
- **สมอของมัตแตนต์มีสองครึ่ง และเครื่องมือตรวจครึ่งเดียว** `anchors.py` อ่านครึ่งสมอ ไม่อ่าน
  ครึ่งแทนที่ — การแก้ที่ขยับบรรทัดท้ายของบล็อกจึงต้องแก้ทั้งสองครึ่ง และรู้ได้จากการกวาดเท่านั้น
- **ตัวนับมาร์กที่เขียนเองหยิบคอลัมน์ไม่ตรงกับ `anchors.py`** มันหยิบคอลัมน์แรกที่หัวตารางเข้าเกณฑ์
  ให้ import `_mark_column` กับ `_cells` ของมันมาใช้ แทนที่จะเขียนตัวอ่านที่สอง (#141, #174)
- **`grep -rn` ทั้ง `e2e/` ค้างได้** เพราะ `test-results/` โตมากหลังการกวาด · grep ไฟล์ที่ต้องการ
  ตรง ๆ และห้าม grep ต้นไม้ขณะชุดทดสอบหรือฮาร์เนสรัน
- **อย่าพิมพ์ไทยด้วย codepoint แล้วไม่สแกนซ้ำ** รอบนี้ `\u` ที่พิมพ์มือกลายเป็น *เมิพาะ* แทน
  *เฉพาะ* และสคริปต์พังทันที — เขียนสคริปต์ด้วยไทยตรง ๆ ผ่านเครื่องมือเขียนไฟล์ แล้ว Read ดู
- **heredoc กินแบ็กสแลช** — เขียนสคริปต์แก้ไฟล์ด้วยเครื่องมือเขียนไฟล์ และ **ยึดสมอบน ASCII**
  ที่ไม่ซ้ำ
- **อย่ารัน `npm run format` หรือ `npx prettier --write`** (#189) · prettier ที่ติดตั้งใหม่กว่า
  สไตล์ที่คอมมิตไว้ `--check` จึงเตือนทั้งต้นไม้อยู่แล้ว ไม่ใช่สัญญาณของการแก้รอบนี้

  `netsh interface ipv4 show excludedportrange protocol=tcp` **ทุกครั้ง** แล้วเลือกจากนอกช่วง
  อย่ายกพอร์ตจากใบนี้ไปใช้ (รอบนี้ใช้ 3400/5310)
- **คอนเทนเนอร์ `deep-core-postgres` ต้องสตาร์ตหลังรีบูต** อาการคือ webServer timeout
- **คอนโซลเป็น cp874** อย่าพิมพ์ไทยหรือ ☑⚙◐☐ ผ่าน Bash · ส่งไทยขึ้น GitHub ด้วย `--body-file`
  กับพาธแบบ Windows และ `MSYS_NO_PATHCONV=1` · `gh issue close` **ไม่มี** `--comment-file` ·
  ข้อความคอมมิตภาษาไทยส่งด้วย `git commit -F <file>`
