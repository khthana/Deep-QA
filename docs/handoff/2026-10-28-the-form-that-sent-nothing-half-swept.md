## สถานะของ #242 — ข้อของตั๋วไหนเสร็จแล้ว

ตั๋วขอห้าข้อ ([`_local/issue242.md`](../../_local/issue242.md) คือตัวบทที่ดึงมาอ่าน)

**ข้อ 1 — วัดทางเข้าที่ seam ก่อน · เสร็จ และคำตอบคือสร้างได้** รันเก้าแถวใหม่กับโค้ดที่ยังไม่แก้
เมื่อ 28 ต.ค. 2569 ได้ **แดงแปดจาก** เก้า แต่ละแถวตายที่ข้อยืนยันที่มันถูกตั้งชื่อตาม ฉะนั้น
#242 เป็น**ข้อบกพร่องที่คนพบได้วันนี้ ไม่ใช่คำถามของเจ้าของงาน** หน้าต่างคือหนึ่งรอบ HTTP
และไม่มีนาฬิกาอะไรเลือกให้ ([#199](https://github.com/khthana/Deep-QA/issues/199))

**ข้อ 2 — แถวหนึ่งต่อจอ แบบ `228a` · เสร็จ** `e2e/tests/242a-the-form-that-sent-nothing.spec.js`
**เก้าแถว เขียวหมด** (57 วินาที) สองแถวต่อจอ บวกแถวคำปฏิเสธของจอผลการเรียนรู้

สิ่งที่การวัดเปลี่ยนในการออกแบบแถว: *ยกเลิก* ถูกอ่านใน**แถวที่สอง** ไม่ใช่แถวแรกอย่างที่ `228a`
ทำ เพราะร่างแรกวางข้อยืนยันนั้นไว้กลางแถวแรก แล้วทั้งสี่แถวแรกตายที่นั่นกับโค้ดที่ยังไม่แก้
และขั้นที่ตั๋วสั่งให้วัด — ฟอร์มที่เปิดทีหลังยังพิมพ์ได้ไหม — **ไม่ถูกอ่านเลย**
([#88](https://github.com/khthana/Deep-QA/issues/88) ที่วัดได้ ไม่ใช่ที่คิดเอา)

**ข้อ 3 — ลงรูปของ #228 ที่สี่ฟอร์ม พร้อมสามบรรทัดของการ์ดในสี่จอ · เสร็จ**
ฟอร์ม `PloForm.js` `ProgramSubjectForm.js` `RubricForm.js` `CriterionForm.js` ได้
`const [sending, setSending] = useState(false)` ทุกช่องกรอกอ่านธงนั้น *บันทึก* ยังอ่าน `busy`
และ *ยกเลิก* ไม่ถือธงอะไรเลย · จอ `Plos.js` `ProgramSubjects.js` `Rubrics.js`
`RubricCriteria.js` ได้ `const sent = showing.current` กับการ์ดสามบรรทัด และ**เหตุผลแปดจุดที่
เขียนไว้ว่าการ์ดนี้ไม่มีแถวไปถึง ถูกเขียนใหม่ว่าเงื่อนไขของมันหมดอายุแล้ว** ซึ่งเป็นเงื่อนไขที่
ตัวมันเขียนกำกับตัวเองไว้ตั้งแต่ #202

ราคาที่วัดจาก**การกด** ([#199](https://github.com/khthana/Deep-QA/issues/199) ·
[#221](https://github.com/khthana/Deep-QA/issues/221)) ไม่ได้เปลี่ยนคำตอบ จึงไม่ได้กลับไปถาม
เจ้าของงาน: `cancelDuringSave` ของ `142a` เคยชี้สามจอของ #228 **ตอนนี้ชี้เจ็ดจอ** เพราะสี่จอนี้
เพิ่งมี *ยกเลิก* ที่กดได้ขณะการบันทึกค้างอยู่ (ก่อนนั้นแขนนั้นเริ่มไม่ได้เลย) ส่วน `146a` ไม่ได้
รับสี่จอนี้เข้าไป เพราะคำถามของมันที่สี่จอนี้คือ**แถวที่สองของ `242a`** เอง และเขียนไว้ในหัวแฟ้ม
ทั้งสองแล้ว

**ข้อ 4 — ช่องที่ไม่ถือธงอะไรเลยใน `ProgramSubjectForm.js` · ถูกหักล้าง ไม่ใช่ถูกแก้**
ตัวควบคุมทั้งห้าที่ถือธงได้ถือ `busy` อยู่ครบ และ `<input>` อีกตัวเดียวในฟอร์ม — ช่อง *รายวิชา*
บนการแก้ — เป็น `disabled readOnly` **โดยไม่มีเงื่อนไข** ฉะนั้นมันไม่เคยแยกจากสิ่งที่กำลังถูก
บันทึกได้ ตัวเลข *4 จาก 5* ในตารางของตั๋วถูกต้องตามตัวอักษร (ช่องนั้นไม่มี `busy`) และผิดใน
ผลที่ตามมา — **ยังไม่ได้เขียนลงคอมเมนต์ปิดหรือลงใบ** (ดู §สิ่งที่ยังค้าง)

**ข้อ 5 — ครึ่ง *hint* ไม่เกี่ยวกับใบนี้** ไม่ได้แตะ

## สิ่งที่จะเสียเวลาถ้าไม่รู้

- **`43ae047` กับคอมมิตของ #242 ยัง push ไม่ขึ้น** — push เมื่อผู้ใช้สั่ง ทุกครั้ง
- **การกวาดในพื้นหลังถูกระบบหยุดได้เมื่อเครื่องเหลือหน่วยความจำน้อย** และเมื่อถูกหยุด **มัตแตนต์
  ตัวที่กำลังรันค้างอยู่ในต้นไม้** สิ่งแรกที่ต้องทำคือ `restore` แล้วอ่าน `git status` (ของรอบนี้
  คืนแล้ว ไม่มีอะไรค้าง และไม่มีเซิร์ฟเวอร์ฟังอยู่ที่ 3100/5100/3700) และ**อย่าเริ่มใหม่เองจนผู้ใช้สั่ง**
- **`& npx playwright test` ใน PowerShell ล้มทันที** ด้วย `npm error could not determine
  executable to run` — เรียกโดย**ไม่มี** call operator (`$out = npx playwright test ... 2>&1`)
  แล้วมันทำงาน ถ้าไม่รู้ จะได้บันทึกการกวาดที่ทุกตัว "ไม่มีผล" ภายในสามสิบวินาที ซึ่งอ่านเหมือน
  มัตแตนต์ที่ไม่ฆ่าอะไรเลยทั้งแฟ้ม
- Playwright ยังรันผ่าน Bash ไม่ได้ ใช้เครื่องมือ PowerShell และบูตนี้ตั้ง `E2E_BACKEND_PORT=3700`
- `restore` ปฏิเสธถ้าต้นไม้ไม่ใช่สำเนาของ backup — นั่นคือ `save` ที่ยังไม่ได้ทำ ไม่ใช่ข้อผิดพลาด
