## เรื่องที่จะกินเวลาถ้าไม่รู้ (gotchas)

- **clone อื่นยังมี `master` ที่ตายแล้ว** ปลายทางเปลี่ยนเป็น `main` แล้ว clone เก่าต้องแก้มือ:
  `git branch -m master main && git fetch origin && git branch -u origin/main main && git remote set-head origin -a`
- **พอร์ต 3100/5100 ของ `e2e/` ถูก Windows จองไว้** อาการคือ "already running" หรือ webServer
  "exited early" อ่าน `netsh interface ipv4 show excludedportrange protocol=tcp` **ทุกครั้ง**
  แล้วเลือกจากนอกช่วง อย่ายกพอร์ตจากใบนี้ไปใช้ รอบนี้ใช้
  `E2E_BACKEND_PORT=3400 E2E_FRONTEND_PORT=5310`
- **แท็บที่ไม่ได้อยู่หน้าสุดถ่ายภาพออกมาดำ** ขณะที่ DOM ยังอ่านถูก และ**พาธของรูปที่พิมพ์ลงใน
  คำตอบไม่ถึงใคร** — ถามว่าอะไรอยู่หน้าสุดก่อนถ่าย แล้ว**ส่งรูป**ไป ไม่ใช่ส่งพาธ (#184)
- **การซูมหน้าเพื่ออ่านสีผลักคำอธิบายแถบสีออกนอกจอ** รอบนี้ซูม 1.7 แล้วคำอธิบายหาย กลับไป 1.0
  สำหรับใบ 42 และใช้ `scrollIntoView({inline:'center'})` คู่กับ `window.scrollBy` สำหรับใบ 44
- **อย่ารัน `npm run format` หรือ `npx prettier --write`** prettier ที่ติดตั้งใหม่กว่าสไตล์ที่คอมมิตไว้
- **คอนโซลเป็น cp874** อย่าพิมพ์ไทยหรือ ☑⚙◐☐ ผ่าน Bash ใช้ Read/Grep หรือ redirect ลงไฟล์แล้ว
  Read หรือ `PYTHONIOENCODING=utf-8` · ส่งไทยขึ้น GitHub ด้วย `--body-file` กับพาธแบบ Windows
  และ `MSYS_NO_PATHCONV=1` · `gh issue close` **ไม่มี** `--comment-file` ใช้ `gh issue comment`
  แล้วค่อย `close`
- **`checkthai.py` รับพาธนอกรีโปไม่ได้** (`git diff` ตอบ *outside repository*) รอบนี้คัดลอกไฟล์
  คอมเมนต์เข้ามาไว้ใต้ `docs/` เป็นไฟล์ชั่วคราว ตรวจ แล้วลบ
- **JSON ของ `gh` ที่ไปเข้า `python -c` ตายด้วย surrogate** (`'\udc82'`) redirect ลง `.json`
  แล้วอ่านด้วย `io.open(..., encoding='utf-8')`
- **ห้ามแก้ไฟล์ใน `frontend/`, `e2e/` หรือ `mutation/` ขณะชุดทดสอบหรือฮาร์เนสรัน** รอบนี้ถือการ
