### [#193](https://github.com/khthana/Deep-QA/issues/193) — มัตแตนต์ที่ขาดของทิศการให้

**ตั๋วใบนี้คือคำทำนายของ #77 และคำทำนายถูกวัดก่อน** รูปที่มันเสนอถูก ไซต์ที่มันเสนอผิด
memo ของ `allRoles` ที่ `attachRoles` ทำให้การอ่านที่ค้างเป็น **ทั้งก้อน** ของ `req.auth`
จึงถึง `/api/me` ด้วย เปลือกวาดจากมัน แล้วแถวตายที่ปุ่มบทบาทซึ่งอยู่ **เหนือ** 200 ที่เป็นเป้า
— 200 จะเหลือไม่ถูกพิสูจน์เท่าเดิม หลังแถวแดงและเกียร์ที่ดูเหมือนได้มาแล้ว

`M13` จึงลงที่ `requireRole` ซึ่งเป็นที่ที่ 200 ถูกตัดสิน และ `/api/me` ถูก mount เหนือ
`requireRole` ทุกตัวใน `app.js` เปลือกจึงยังอ่านสด แถวตายที่ assertion ของตัวเอง
**กฎคือฝาแฝดของกฎเรื่องราคาที่ตั๋วประเมิน — รูปของมัตแตนต์ที่ตั๋วเสนอเป็นข้ออ้างเหมือนตัวเลขของมัน
และสิ่งที่ข้ออ้างพูดถึง ไม่ใช่ที่ที่มัตแตนต์ต้องลงเสมอไป** ไซต์เลือกจากบรรทัดที่ต้องแดง

ข้ออ้างสามข้อของตั๋วหมดอายุในสองวัน (`backend/app.js:115` ไม่ใช่ `:108` · มัตแตนต์ 886 ไม่ใช่ 883
· assertion 200 อยู่สองแถวไม่ใช่แถวเดียว) สองข้อแรกเป็นสายพันธุ์ของ #173 พอดี

### [#173](https://github.com/khthana/Deep-QA/issues/173) — อ้าง assertion ด้วยชื่อ

วัดก่อนแก้ และ **ใบนี้ถูกทั้งใบ** เลขแปดตัวที่ชี้เข้า `10a-shell.spec.js` ผิดทั้งแปด ห่าง
**14 ถึง 22 บรรทัดโดยระยะไม่เท่ากัน** จึงไม่มี offset เดียวที่แก้ได้ทั้งตาราง และไฟล์โตอีก
**สิบเอ็ดบรรทัดระหว่างที่แปลงตารางอยู่** (412 → 423) ส่วนการอ้างเข้า `11a` **ยังตรง**
ซึ่งเป็นกรณีรูปธรรมที่ทำให้คำถามนี้ต้องตอบสามอย่าง ไม่ใช่สอง (#159)

ทั้ง 11 แถวอ้างด้วยรูป `` `spec:สตริง` `` ซึ่งเป็นสำนวนของคลังเองอยู่แล้ว (รูป `` `10a:194` ``
มีอยู่ 37 ที่) เปลี่ยนข้อเดียวคือ **สตริงที่หาได้ อยู่ในที่ของเลขที่นับได้** และเข็มทั้ง 14 อัน
ปรากฏ **ครั้งเดียว** ในไฟล์ของมัน — วัดแล้ว ซึ่งเป็นข้ออ้างที่การอ้างด้วยข้อความตั้งอยู่บนนั้นทั้งหมด

**กฎแรกที่ลองแล้วทิ้ง** คือการอ่านวลีตัวเอียงเป็นการอ้าง รันกับคลังจริงได้ 6 ข้อ **4 ข้อเป็นบวกลวง**
อัตราผิดราว 25% บนประชากรหกข้อไม่ใช่เครื่องมือ · **สองที่ที่ชื่อต้องใส่ลงใน spec** คือ assertion
สองอันที่เป็นบรรทัดโค้ดเดียวกันสองครั้งในแถวเดียวกัน และเป็นที่ตายของมัตแตนต์สองตัวต่างกัน
ซึ่งไม่มีการอ้างด้วยข้อความใดแยกได้ ทั้งสองได้ `message` ของตัวเอง

**หนี้เขียนพร้อมจำนวน และแยกตามสิ่งที่เลขชี้เข้าไป** เพราะตัวเลขที่บวกรวมกันเป็นของเครื่องมือ

```
citations: by name 14 | of those gone 0 | inside a fence, counted and not read 5 | unreadable 0 | problems 0
citations: by number 442 - 38 into a spec, 99 into something that is not a spec, 305 with no file beside the number
```

### รอบรีวิวของ #173 — สามข้อ และทั้งสามอยู่ในเครื่องมือเอง

1. **กฎรีโซลฟ์เป็น glob** ทั้งที่รีโปวัดและเขียนไว้แล้ว — ประโยคแรกของใบนี้ พอแก้เป็น substring
   เครื่องมือ **แดงทันที** และชี้การอ้างกำกวมจริงหนึ่งแห่ง (`22a` จับได้ทั้ง `22a-rubric-criteria`
   และ `122a-weight-total-in-words`) ยืนยันด้วยการอ่าน spec ทั้งสองไฟล์แล้วเขียนชื่อไฟล์ให้ครบ
2. **`CANNOT ASK` ไม่เคยถึง exit code** จึงเป็นคำตอบที่สี่ ไม่ใช่ที่สาม — ถ้าไม่มี `e2e/tests`
   เครื่องจะพิมพ์สิบสี่บรรทัดแล้ว exit 0 ว่าคลังสะอาด ทั้งที่ไม่เคยถาม สามคำถามข้างบนนับเป็น
   problem ทั้งหมด **ความผิดพลาดของ #159 ในตั๋วที่เอกสารของมันเองอ้าง #159**
3. **จำนวนที่ข้าม fence พิมพ์แต่ไม่คืนค่า** แถวจึงแยก *นับออกเสียง* (#126) จาก *เมินเงียบ ๆ* ไม่ได้

พังทั้งสามข้อทีละข้อแล้ววัด แต่ละข้อทำให้แดง **เฉพาะแถวของตัวเอง** แล้ว restore ใน `finally`

  และ `MSYS_NO_PATHCONV=1`
- **ห้ามแก้ไฟล์ใน `frontend/`, `e2e/` หรือ `mutation/` ขณะชุดทดสอบหรือฮาร์เนสรัน** การแก้แม้แต่
