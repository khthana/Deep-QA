## สิ่งที่วัดได้

**ทุกข้อในคำวินิจฉัยของตั๋วเป็นจริง** ซึ่งเป็นผลที่พบน้อยกว่า (#66) ยามยังเป็นบรรทัดที่ตั๋วอ้าง
ผู้อ่านสามรายอ่านเพื่อแสดงเท่านั้น และปีที่ผิดได้ประโยคกลาง *ข้อมูลหลักสูตรไม่ครบถ้วนหรือไม่ถูกต้อง*
สองอย่างที่ตั๋วไม่ได้เขียน มาจากการวัดรอบ ๆ มัน

- **`lib/year.js` เป็นภาพกลับ** ตั๋วเสนอมันแล้วปัดว่า *ไม่เหมาะ* ซึ่งอ่านเหมือนคำตัดสินเรื่องสไตล์
  พอรันมันเป็นคำหักล้าง (เลขอยู่ในย่อหน้าบนสุด)
- **ไม่มีขอบไหนในยามของเซิร์ฟเวอร์นี้ที่คิดมาจากนาฬิกา** เพดานแบบ *อีกไม่กี่ปีจากวันนี้*
  จะเป็นขอบตัวแรกของระบบที่ขยับไปตามวัน (#52) — การวัดนี้ส่งไปกับคำถาม ไม่ใช่ส่งไปเป็น
  ข้อเสนอที่แต่งตัวเป็นข้อเท็จจริง
- **และถ้อยคำแรกของประโยคนั้นผิด การรีวิวจับได้** ที่เขียนลงไปสี่แฟ้มก่อนคือ *ไม่มียามไหนใน
  เซิร์ฟเวอร์นี้อ่านนาฬิกา* ซึ่งมาจากการสำรวจที่ grep `Date.now()` · `validityRefusal` ใน
  `auth/accounts.js` อ่านนาฬิกาจริง (`today = BANGKOK.format(new Date())`) ทั้งสองทางเข้า
  **grep เป็นหลักฐานของแพตเทิร์นที่พิมพ์ลงไป** (#111, #124) และที่พิมพ์ลงไปคือหนึ่งในสองการสะกด
  · สิ่งที่จริงแคบกว่า และเป็นประโยคที่คำตอบของเจ้าของงานยืนอยู่บนจริง ๆ คือ ยามตัวนั้นอ่านนาฬิกา
  เพื่อเทียบ *ช่วงเวลาที่มีคนบันทึกไว้* กับวันนี้ ไม่ใช่เพื่อเลือกขอบของตัวเอง · การแก้ไปถึง
  **ห้าแฟ้ม** เพราะข้ออ้างที่เขียนเป็นร้อยแก้วหมดอายุเหมือนตัวเลข (#130)

**ยามใหม่อยู่ที่สอง และนั่นคือสิ่งที่ทำให้แถวที่เดินแล้วของตั๋วที่ปิดไปยังจริง** (#60) `25`
ไม่มีปีอยู่ในนั้นให้คิดเลข ยามเรื่องรูปร่างจึงถูกถามก่อนและตอบอย่างที่เคยตอบ แถว
*ปีหลักสูตรต้องเป็นสี่หลัก* ของใบ 15 ซึ่งบันทึกประโยคกลางนั้นไว้จากการเดินด้วย curl เมื่อ ส.ค. 2569
จึงอ่านได้เหมือนเดิม มันได้ประโยคต่อท้ายว่าสี่หลักยังไม่พอ ผลของมันไม่เปลี่ยน

**ข้อต่อหนึ่งของยามมีมัตแตนต์แยกไม่ได้** ค่าที่ประโยคแปลงศักราชมีไว้เพื่อมัน (2024) อยู่ **ใต้**
พื้นของช่วง ตัวที่เลิกอ่านพื้นจึงเลิกปฏิเสธ 2024 ด้วย และตายที่แถวเดียวกับ `theyearisonlyshaped`
คือเป็นสำเนาของมัน ไม่ใช่ข้ออ้างที่สอง — แฟ้มมัตแตนต์เขียนไว้ว่านี่คือข้อที่สองของสามข้อตาม #101
คือ *ไปถึงไม่ได้เชิงโครงสร้าง* ไม่ใช่ช่องว่าง

- **`lib/year.js` ไม่ใช่บ้านของปีหลักสูตร** และมันจะ *ดู* เหมือนบ้านตลอดไป — ช่วงของมันเป็น
  คริสต์ศักราช รันมันก่อนเชื่อชื่อมัน (`node -e` สองบรรทัดก็พอ)
- **ปีที่ว่างไม่ถูกตรวจ** `revision_year` เป็น nullable และยามทั้งสองตัวอยู่ใต้
  `if (values.revision_year)` — แถว *1 ล้างปี* ของใบ 15 จึงยังตอบ `200`
- **ค่าในฟิกซ์เจอร์ที่อยู่นอกช่วงจะกลายเป็น 400** ทุกค่าใน seed และใน spec ของ e2e วันนี้อยู่ใน
  2500–2600 แล้ว (ตรวจแล้วก่อนกวาด) ถ้าจะเติมฟิกซ์เจอร์ใหม่ อย่าใช้ปี ค.ศ.
- **clone อื่นยังมี `master` ที่ตายแล้ว** — `git branch -m master main && git fetch origin &&
  git branch -u origin/main main && git remote set-head origin -a`
- **พอร์ต 5100/3100 อยู่ในช่วงที่ Windows จองไว้บางเครื่อง** อ่าน
  `netsh int ipv4 show excludedportrange protocol=tcp` ก่อนเชื่อว่า "มีอะไรรันอยู่"
- **อย่า `git add` อะไรใต้ `DEEP-QA-BACKEND/` หรือ `_local/`** และ `git add -A` ถูกปฏิเสธที่นี่ —
  stage ทีละ path
- **Playwright ผ่าน Bash ถูกปฏิเสธที่เครื่องนี้** ใช้เครื่องมือ PowerShell รันคำสั่งเดียวกัน
- `python mutation/anchors.py` ต้องมี `PYTHONIOENCODING=utf-8`
- คอนโซลเป็น cp874 — **อย่าพิมพ์ไทยหรือ ☑⚙◐☐ ออกมาทาง Bash** อ่านด้วยเครื่องมือ Read
- **อย่า rewrap ย่อหน้าไทยด้วย `textwrap`** มันต่อบรรทัดด้วยช่องว่าง แล้วคำไทยที่ถูกตัดข้ามบรรทัด
  จะกลายเป็นสองคำ — ขึ้นบรรทัดใหม่ด้วยมือ
- **อย่ารัน `npm run format` หรือ `prettier --write`** (#189)
