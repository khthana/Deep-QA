## 6. Gotchas that cost time

- **A fresh clone lands on a dead `master`.** Run, verbatim:
  `git branch -m master main && git fetch origin --prune && git branch -u origin/main main`
- **Never run the e2e stack while the dev stack is up.** CRA starves it, the `webServer` times out
  at 240 s, and the run reports green having tested nothing. Stop both servers first — and note
  that stopping the background task is not enough on Windows: the `node` processes survive it.
  Check with `netstat -ano | grep -E ":(3000|5000)\s.*LISTENING"` and `taskkill //PID n //T //F`.
- **Sign-in through the browser tools needs a real click.** `form_input` on the two fields followed
  by Enter does not submit. Fill both fields, then click *Login to your account* by coordinate —
  it sat at ≈(1098, 558) — and wait eight seconds.
- **A logout click can land mid-fade and not take.** Confirm with `/api/me` rather than the screen.
  The first screenshot after each sign-in shows the sidebar text overlapping; that is the submenu
  animation in flight, not a defect. Wait four seconds.
- Everything in section 6 of `2026-08-20-two-seams.md` still applies: cp874, `rev`, `gh --body-file`,
  U+FEFF, the mutation backup keying, and `toBeDisabled()` on an `<option>`.
