## เรื่องที่คุ้มกับการเล่าใน #160

**สาม ย่อหน้าละเรื่อง**

*หนึ่ง — รั้วอยู่ผิดจุดในรอบแรก* คำขอถูกส่งก่อนและตอบทีหลัง ระหว่างนั้นเอกสารเก่ายังอยู่บนจอและยังยิงคำขอได้
รั้วที่คำขอจึงเก็บคำขอพวกนั้นเข้าไปด้วย — บีบให้แคบ ไม่ได้ปิด ทั้งที่ docstring เขียนว่าปิด ผู้ตรวจทั้งสองแกน
เจอข้อเดียวกันด้วยถ้อยคำเดียวกัน ย้ายไปที่ commit แล้วฝั่งไกลของรั้วไม่มีอะไรนอกจากเอกสารใหม่

*สอง — แถวแรกผ่านแม้ลบ clause ของรั้วทิ้ง* คำขอค้างของมันเกิด**ก่อน** `openAt` จะถูกเรียกด้วยซ้ำ มันจึงพิสูจน์
ตัวกรองด้วย identity แต่ไม่ได้พูดอะไรเลยว่าเส้นอยู่ตรงไหน **แถวที่ผ่านทั้งที่ลบ clause ทิ้ง คือแถวที่ไปไม่ถึง
clause นั้น** แถวที่สองจึงสร้างคำขอที่เอกสารเก่าถาม *หลัง* ตัวช่วยเริ่มแล้ว และการสร้างมันต้องวัดเอง:
`page.evaluate` ใช้ไม่ได้เมื่อ main frame มีการนำทางค้างอยู่ (`net::ERR_ABORTED; maybe frame was detached?`)
คำถามจึงถูกตั้งไว้ก่อนแล้วให้มันต่ออายุตัวเอง — คำตอบหนึ่งลงปุ๊บ อันถัดไปออกปั๊บ — ไม่มีอะไรรอระยะเวลา
**สถานการณ์ที่สร้างตอนที่ต้องการไม่ได้ บางทีสร้างเป็นข้อเสนอค้างไว้ได้**

*สาม — เอกสารที่ถูกส่งให้หน้าด้วย `route.fulfill` มาถึงโดยไม่มี address space ของตัวเอง* Chromium ปฏิเสธ
ทุกคำขอที่หน้าใหม่ยิงไป `localhost` ว่าเป็น local-network request จอไม่เห็น `/api/me` แล้วเด้งกลับฟอร์มลงชื่อ
เข้าใช้ — ซึ่งหน้าตาเหมือนตัวแก้ที่กำลังทดสอบไม่ทำงานเป๊ะ เสียเวลาไปทั้งบ่าย สิ่งที่ยุติมันคือ snapshot ที่
Playwright เซฟไว้ (บอกว่าจออยู่ที่ฟอร์มลงชื่อเข้าใช้) กับ console (บอกประโยค CORS ตรง ๆ) **stack บอกว่าคุณรอ
อยู่ตรงไหน snapshot บอกว่าจอตัดสินใจอะไร — อ่านอย่างหลังก่อน** `gateNavigation` ใน `gate.js` กักการนำทางแล้ว
`route.continue()` ให้เบราว์เซอร์ไปดึงเอกสารเอง

**ไม่มีไฟล์ `mutation/160-*.py`** เพราะ harness ไม่ใช่สิ่งที่ `mutation/` กลายพันธุ์ สิ่งที่แทนคือ**ตัวคุมสองตัว
ตัวละแถว** รันด้วยมือ: เอารูปแบบ `Promise.all` เดิมกลับไปใส่ `openDashboard` แถวหนึ่งตายด้วย protocol error
ตามตั๋ว · ย้ายรั้วกลับไปที่คำขอ แถวสองตาย ด้วยประโยคของ `openAt` เอง (ซึ่งคือข้อ 2 วัดในรันเดียวกัน)
แต่ละตัวฆ่าแถวเดียวและปล่อยอีกแถวยืน — เขียนไว้บน docstring ของ `160a` แล้ว

**รัศมีที่ตั๋วบอกผิด** ตั๋วบอก 38 ไฟล์ วัดจริงที่ `d41ca51`: 34 ไฟล์มี `page.goto` และ **32** ใช้รูปแบบนั้น
อีกสองคือ `auth.js` กับ `sign-in-screen.js` ที่ `goto` เฉย ๆ ไม่คืน response จึงแพ้การแข่งนี้ไม่ได้
