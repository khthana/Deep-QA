## เรื่องที่ต้องรู้ก่อนเริ่ม (gotchas)

- **clone บนเครื่องอื่นยังมี `master` ที่ตาย** `origin/master` ไม่มีแล้ว clone ไหนที่ยังไม่ได้ซ่อมต้องรันมือ:

  ```bash
  git branch -m master main && git fetch origin --prune && git branch -u origin/main main
  ```

- **ก่อนเดินด้วยมือ ให้ `cd db && npm run migrate` เสมอ** (#159) — และสแตกเดินคือ
  `docker start deep-core-postgres` (พอร์ต **5433**) · `cd db && npm run reset && npm run migrate && npm run seed`
  · backend พอร์ต 3000 · frontend พอร์ต 5000
- **พอร์ต 3000 มี `grader-app-1` นั่งอยู่** ถ้าจะเดิน ต้องให้เจ้าของหยุดมันก่อน และ **คืนด้วย
  `docker start grader-app-1` เมื่อจบ** — การสั่งหยุดคอนเทนเนอร์ของคนอื่นถูกปฏิเสธโดยตัวจัดสิทธิ์
- **เซิร์ฟเวอร์ที่ต้องอยู่ข้ามคำสั่ง ต้องเป็น `nohup … > log 2>&1 & disown` ในคำสั่ง Bash ครั้งเดียว**
  แล้ว `curl --retry` ในคำสั่งเดียวกัน — task เบื้องหลัง `Start-Process` `cmd /c start` และ WMI
  ถูกเก็บกวาดทั้งหมด อาการคือพิมพ์ *Server running* แล้วจบด้วย exit 0
- **แท็บ Chrome ที่ `visibilityState` เป็น `hidden` ถ่ายรูปออกมาดำ** แต่ JS ยังตอบถูก ถามแท็บก่อนถ่าย
  และการพิมพ์ path ของรูปลงในคำตอบ **ไม่ถึงคนอ่าน** ต้องส่งเป็นไฟล์
- **สคริปต์แก้ไฟล์ต้องยึดกับข้อความ ASCII ไม่ใช่ข้อความไทย** และ **ภาษาไทยยาว ๆ ห้ามผ่าน heredoc**
  เขียนสคริปต์ลงไฟล์ก่อนแล้วรัน แล้ว**พิสูจน์อักษรด้วยการอ่านไดฟ์** ไม่ใช่ด้วยคอนโซล
- **`npm test` ของ backend คือ `node --test "test/*.test.js"`** · `node --test scripts/` ล้ม ต้องเป็นกลอบในคำพูด
- **`E2E_BACKEND_PORT=3110 E2E_FRONTEND_PORT=5300`** พอร์ต 5100 กับ 3100 ถูก Windows จองไว้
- **อ้างสเปกด้วยชื่อเต็มเสมอ** `npx playwright test 22a` รัน `122a` ด้วย (#158)
- **ระหว่างกวาด ต้นไม้เป็นของ harness** grep หรือ anchor check ตอนนั้นอ่านมัตแตนต์ ไม่ใช่โค้ด
- **อย่า grep ผลของการรันชุดทดสอบสด ๆ** ให้รันลงไฟล์แล้วค่อยอ่านไฟล์
