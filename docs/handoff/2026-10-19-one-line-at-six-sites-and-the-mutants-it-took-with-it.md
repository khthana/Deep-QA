## เรื่องที่จะกินเวลาถ้าไม่รู้ (gotchas)

- **โคลนอื่นยังมี `master` ที่ตายแล้ว** — สาขาหลักชื่อ `main` แล้ว ในโคลนเก่าให้รัน
  `git branch -m master main && git fetch origin && git branch -u origin/main main &&
  git remote set-head origin -a`
- **`python mutation/anchors_test.py` ต้องมี `PYTHONIOENCODING=utf-8`** บนเครื่องนี้ ไม่งั้นมันล้ม
  ตอนพิมพ์ ◐ ด้วย cp874 — ไม่ใช่ความผิดของเทสต์
- **`npm run census` รันจาก `frontend/`** จากรากคลังมันตาย `ENOENT … package.json`
- **ห้ามแก้ `frontend/` `e2e/` หรือ `mutation/` ขณะชุดเบราว์เซอร์หรือตัวกวาดรันอยู่** (hot reload
  ปนการรัน) และ **ห้าม grep การรันสด** · ร้อยแก้วใน `docs/` แก้ได้
- **`npx prettier --check` เตือนทั้งต้นไม้** — 105 จาก 105 แฟ้มใน `e2e/` เตือนที่ HEAD การเตือน
  แฟ้มที่เพิ่งเขียนจึงไม่ใช่ข้อค้นพบ และ **ห้ามรัน `--write` หรือ `npm run format`** (#189)
- **สองแฟ้มถือครึ่งละข้างของข้ออ้างเรื่อง `busy`** — `210a` ถือ `ถัดไป` ที่หน้า 1 และ `207a`
  (ตาข่าย) ถือ `ก่อนหน้า` ที่หน้าสุดท้าย ใครจะเพิ่มการอ่านปุ่มอีกข้างในแฟ้มใดแฟ้มหนึ่ง ต้องย้ายแถว
  ไปหน้ากลางก่อน ไม่งั้นได้ assertion ที่ล้มไม่ได้ (#50, #214)
