## สิ่งที่วัดได้ และเป็นเหตุให้คำตอบเป็น "ปล่อยไว้"

โพรบ Playwright ที่สร้าง รัน แล้วลบ (#207) เล็ง CDP ไปที่ปุ่มทั้งสอง — ตั้ง attribute เป็นหมาย
บน element ที่ locator หาได้ แล้ว `DOM.describeNode` · `Accessibility.getPartialAXTree` ·
`Accessibility.getFullAXTree` จับคู่ด้วย `backendDOMNodeId` — แล้วอ่าน node ที่ Chrome คำนวณเอง

| | *ระงับ* บนแถวของตัวเอง | ตัวคุม (ปุ่มเดียวกันแถวอื่น) | *ยกเลิกบทบาท* บนสิทธิ์ของตัวเอง |
|---|---|---|---|
| อยู่ใน full AX tree | **ใช่** `ignored: false` role `button` | ใช่ | **ใช่** `ignored: false` role `button` |
| `title` → accessible **description** | **ใช่ 25 ตัวอักษร** = `REFUSALS.selfStatus` | ไม่มี | **ใช่ 26 ตัวอักษร** = `REFUSALS.selfRevoke` |
| ชื่อปุ่มมาจาก | `contents` + `attribute` | `contents` | `contents` + `attribute` |
| `focusable` | **ไม่มี property นี้เลย** | `focusable: true` | **ไม่มี** |

ชื่อมาจาก `contents` (attribute ถูก supersede) ฉะนั้น `title` เป็น**คำอธิบาย** ไม่ได้ถูกกลืนเป็นชื่อ ·
คู่บรรทัดล่างสุดคือ **tree ยืนยันการวัด `Tab` ของตั๋วด้วยตัวมันเองพร้อมตัวคุม** ·
**แปลว่าเหตุผลไปถึงเทคโนโลยีช่วยเหลือแล้ว** สิ่งที่ยังวัดไม่ได้จึงไม่ใช่เรื่องของโค้ดนี้
แต่เป็นว่าโปรแกรมอ่านจอตัวนั้นตั้งค่าให้อ่าน object description หรือไม่ ·
วัดใน Chromium ซึ่งเป็น project เดียวในคอนฟิก

**ที่บันทึกตัวเลขชุดนี้ไว้เป็นหลักคือใบ `11-user-accounts.md` ข้อ (ค)** ตารางข้างบนกับ §#163 ใน

## ราคาสามข้อที่ตั๋วไม่ได้ลิสต์ไว้ (ถ้าวันหนึ่งคำตอบเปลี่ยน)

1. **มัตแตนต์เจ็ดตัวอยู่บนบรรทัดที่ทาง WAI-ARIA จะแก้** — `84:alwaysenabled` `84:everyrowisdead`
   `84:titledrifts` `130:alwaysenabled` `130:everyrowisdead` `130:titledrifts`
   `130:selfrowhidesthebutton` สี่ตัวยกบรรทัด `disabled={…}` สองบรรทัดนั้นมาเป๊ะ และสองในสี่
   **จะเลิกมีความหมายตามที่ใบของมันเขียนไว้** เพราะเมื่อด่านย้ายไปที่ handler การทำให้ attribute
   ผิดก็ไม่ใช่การทำให้ปุ่มกลับมามีชีวิตอีกแล้ว — เป็นการ**เขียนใหม่ ไม่ใช่การเล็งใหม่** (#203)
   และต้องตามด้วย sweep (#107 · #68)
2. **คลาส `disabled:` ทุกตัวหยุดทำงานวันที่ attribute หายไป** (`disabled:text-gray-400`
   `disabled:cursor-not-allowed` `disabled:hover:bg-transparent` `disabled:opacity-40`)
   หน้าตาที่เจ้าของงานอนุมัติเมื่อ 24 ก.ย. 2569 — ใบ 11 แถว *ดูออกไหมว่ากดไม่ได้* และใบ 12 แถว
   *ปุ่มที่ตายไม่สว่างขึ้นใต้เมาส์* ทั้งคู่เป็น ☑ — ต้องสร้างใหม่บน `aria-disabled:` แล้วเดินใหม่
3. **`GrantsPanel` เป็น `disabled={busy || isSelf}`** ขา `busy` ไม่มี `title` ด่านที่ handler
   ต้องตอบสองเหตุ ไม่ใช่เหตุเดียว และขา `busy` เป็นเรื่องของ #142

## เรื่องที่จะกินเวลาถ้าไม่รู้ (gotchas)

- **clone อื่นยังมี `master` ที่ตายแล้ว** — `git branch -m master main && git fetch origin &&
  git branch -u origin/main main && git remote set-head origin -a`
- **ถ้าต้องวัด accessibility tree อีก สูตรอยู่ใน `docs/lessons.md` §#163** — ตั้ง attribute
  เป็นหมายบน element ที่ locator หาได้ แล้วเล็ง CDP ด้วย `DOM.querySelector` · `DOM.describeNode`
  · `Accessibility.getFullAXTree` จับคู่ด้วย `backendDOMNodeId` · **`page.accessibility.snapshot`
  ไม่มีอยู่แล้วใน Playwright รุ่นนี้** (`Cannot read properties of undefined`) อย่าเสียเวลากับมัน
- **`description` ที่ไม่มีค่าจะไม่มี key เลยใน JSON** ที่เขียนออกมาจาก CDP (`undefined` หายไปตอน
  `JSON.stringify`) สคริปต์ที่อ่านผลต้องใช้ `.get()` ไม่ใช่ `[...]` ไม่งั้นตายด้วย `KeyError`
- **python ที่นี่เป็นของ Windows** path แบบ `/c/Users/...` ของ Bash มันเปิดไม่ได้ ส่งเป็น
  `C:\Users\...` (raw string) แทน
- **ลบโพรบเมื่อวัด*การแก้*แล้ว ไม่ใช่เมื่อตอบคำถามแล้ว** (#207 · #156) ตั๋วนี้ไม่มีการแก้
  การวัดจึงจบที่คำตอบ และโพรบถูกลบตอนนั้น
- **Playwright ถูกปฏิเสธถ้ารันผ่าน Bash** คำสั่งเดียวกันผ่านเครื่องมือ PowerShell ผ่าน
- **`mutation/.backup/` ยังมีฉบับสำรองของ `Users.js` และ `GrantsPanel.js`** — `save` เป็นคำสั่ง
  แรกเสมอ (#124 · #126) `applied.json` เป็น `{}` คือไม่มีมัตแตนต์ค้าง
- `python mutation/anchors.py` ต้องมี `PYTHONIOENCODING=utf-8` ไม่งั้นมันตายตอนพิมพ์เครื่องหมาย
- คอนโซลเป็น cp874 — **อย่าพิมพ์ไทยหรือ ☑⚙◐☐ ออกมาทาง Bash** อ่านด้วยเครื่องมือ Read
- `npm run census` ต้องรันจาก `frontend/` · `npm test` ของ backend ต้องรันจาก `backend/`
- **อย่ารัน `npm run format` หรือ `prettier --write`** (#189) prettier ที่ติดตั้งใหม่กว่าสไตล์ที่
  commit ไว้ และ `prettier --check` เตือนทั้งต้นไม้อยู่แล้ว
