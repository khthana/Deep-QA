## Gotchas ที่ยังต้องพก

ยกมาทั้งชุดจากใบก่อนหน้า ยังใช้ได้ทุกข้อ และเพิ่มจากรอบนี้ (ห้าข้อแรก)

- **อย่าแก้ไฟล์ที่อยู่ใน `FILES` ของไฟล์มัตแตนต์ ขณะที่ sub-agent (เช่น reviewer) อาจกำลังใส่มัตแตนต์** — รอบ #110
  ผมแก้คอมเมนต์ใน `learningDetails.js` ระหว่างที่ reviewer ใส่ `PASS = 3.2` อยู่ `restore` จึงปฏิเสธ (#126)
  และมัตแตนต์ค้างในต้นไม้ บอก reviewer ว่าห้ามรัน harness หรือรอให้มันจบก่อนแก้ แล้วอ่าน `git diff` ก่อน commit
- **แท็บ Chrome ที่ถูกซ่อนรับการกดปุ่มในช่องวันที่ไม่ได้ และภาพหน้าจอเลื่อนจากพิกัดจริง** — ขอให้เจ้าของงานดึงแท็บขึ้นหน้า
  ช่องวันที่ต้องใช้การกด `key` ทีละตัว ไม่ใช่ `type` และคลิกด้วย ref จาก `find` ดีกว่าพิกัด
- **มัตแตนต์ในโค้ดที่ใช้ร่วม (`backend/lib/`) ต้องกวาดกับชุด backend ทั้งชุด** ไม่ใช่แค่ไฟล์ทดสอบของใบตัวเอง
  — รายการ kill ของ #110 กระจายห้าไฟล์
- **`gh issue close` ไม่มี `--comment-file`** ใช้ `gh issue comment <n> --body-file <f>` แล้วตามด้วย
  `gh issue close <n> --reason completed`
- **ชุดเต็ม e2e ตอนนี้ 506 แถว ใช้ราว 27–28 นาที**
- `git clone` ที่ทำไว้ก่อนเปลี่ยนชื่อ branch ยังชี้ `master` ที่ตายแล้ว แก้ด้วย
  `git remote set-head origin -a && git branch -m master main && git branch -u origin/main`
- **ข้อความ commit ห้ามมีคำปิดตั๋ว** (`close: #N` ก็ปิด) ใช้ `Refs #N` และตรวจด้วย
  `grep -niE '(clos|fix|resolv)[a-z]*:? +#[0-9]'` ก่อน commit
- **`anchors.py` อ่าน anchor ไม่ได้อ่านสิ่งที่มัตแตนต์แทนเข้าไป** — เมื่อเปลี่ยนลายเซ็นของฟังก์ชัน ให้ grep สตริงแทนที่
  ในทุกไฟล์มัตแตนต์ด้วย ไม่ใช่แค่รัน `anchors.py`
- **มัตแตนต์แบบหลายจุดคือ list ของ `(key, old, new)`** ไม่ใช่ `(key, [(old, new)])`
- **`page.unroute(matcher)` ต้องได้ฟังก์ชันตัวเดียวกับที่ส่งให้ `page.route`** — Playwright เทียบด้วย `===`
  และ handler ที่หน่วงคำตอบต้องกลืน error ของ `route.continue()` เมื่อแถวจบและปิดหน้าไปแล้ว
- **สคริปต์นับเครื่องหมายต้องตรวจว่าช่องสุดท้ายยาวหนึ่งตัวอักษร** — ใน Python `'' in 'marks'` เป็นจริง
