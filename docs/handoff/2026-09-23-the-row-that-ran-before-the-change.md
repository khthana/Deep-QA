## เรื่องที่ต้องรู้ก่อนเริ่ม (gotchas)

- **clone บนเครื่องอื่นยังมี `master` ที่ตาย** การเปลี่ยนชื่อ default branch เป็น `main` เมื่อ 17 ส.ค. 2569
  เป็นฝั่ง server เท่านั้น `origin/master` ไม่มีแล้ว clone ไหนที่ยังไม่ได้ซ่อมต้องรันมือ:

  ```bash
  git branch -m master main && git fetch origin --prune && git branch -u origin/main main
  ```

- **ก่อนเดินด้วยมือ ให้ `cd db && npm run migrate` เสมอ** นี่คือ #159 ทั้งใบ ทั้งสอง seam migrate schema ของ
