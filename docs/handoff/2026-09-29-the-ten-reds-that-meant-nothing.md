### [#168](https://github.com/khthana/Deep-QA/issues/168) — รั้วที่เปิดก่อนเอกสารจะมีอยู่ (`c05ffcb`)

`105a` แดงครั้งเดียวในรอบเต็มวันที่ 27 ด้วยประโยคของ #160 เอง ตั๋วขอ**กลไกก่อน ไม่ใช่การแก้** และวัดได้ว่า
`page.on('framenavigated')` ยิงให้ `history.replaceState` ด้วย รั้วจึงเปิดก่อนเอกสารที่ `goto` ขอจะมีอยู่
แล้วเก็บ request ของเอกสารเก่าไว้ — สิ่งเดียวที่ `navigation.js` มีไว้ปฏิเสธ สำรวจใน `openAt`
ทั่วชุดพบว่าไม่ใช่เรื่องหายาก: **389 จาก 621 หน้าต่างเปิดบน commit ที่ยังไม่ได้ fetch อะไรเลย**

รั้วใหม่คือ `Page.frameNavigated` จาก CDP ซึ่งเป็นเหตุการณ์ที่ Chromium แยกจาก
`Page.navigatedWithinDocument` · **ธงบน `isNavigationRequest()` ถูกลองก่อนและวัดได้ว่าผิด** —
request ของเอกสารออกไปแล้ว แต่ commit **ตัวถัดไป** ยังเป็น `replaceState` ซึ่งกินธงนั้นไป
ธงที่จับคู่กับเหตุการณ์ทีหลังไม่ใช่การระบุตัว และ `asked.clear()` ที่ตั๋วขอ **ไม่ได้ใส่** ด้วยตัวเลข

## เรื่องที่ต้องรู้ก่อนเริ่ม (gotchas)

- **clone บนเครื่องอื่นยังมี `master` ที่ตาย** การเปลี่ยนชื่อ default branch เป็น `main` เมื่อ 17 ส.ค. 2569
  เป็นฝั่ง server เท่านั้น `origin/master` ไม่มีแล้ว clone ไหนที่ยังไม่ได้ซ่อมต้องรันมือ:

  ```bash
  git branch -m master main && git fetch origin --prune && git branch -u origin/main main
  ```

- **ก่อนเดินด้วยมือ ให้ `cd db && npm run migrate` เสมอ** นี่คือ #159 ทั้งใบ
- **สคริปต์แก้ไฟล์ต้องยึดกับข้อความ ASCII ไม่ใช่ข้อความไทย** — การเขียนไทยลงในสคริปต์คือการพิมพ์ใหม่
  และการพิมพ์ใหม่คือตัวที่ผิด (`assert t.count(old) == 1` ล้มสองครั้งในวันที่ 29 บนบรรทัดที่เพิ่งเขียนเอง)
  ยึดกับ identifier ใน backtick ประโยคอังกฤษ หรือเลขบรรทัด แล้วคง assert ไว้เพราะมันคือสิ่งที่จับได้
- **สคริปต์ที่เขียนไฟล์ Python อีกไฟล์ — `\n` ในสตริงกลายเป็นบรรทัดจริงในไฟล์ปลายทาง** เขียนไฟล์
  มัตแตนต์ด้วยเครื่องมือเขียนไฟล์ตรง ๆ ดีกว่า (และภาษาไทยยาว ๆ ห้ามผ่าน heredoc ของ Bash)
- **`e2e/support/` ไม่ใช่สิ่งที่ `mutation/` กลายพันธุ์** จุดนิ่งและรั้วในนั้นพิสูจน์ด้วย control รันมือ
  ถอดทีละตัว แล้วรันสเปกของตัวเองพร้อมสเปกของจอนั้น เพื่อให้รอบเดียวบอกทั้งว่ามันฆ่าอะไรและไม่ฆ่าอะไร
- **`npx playwright test --list` นับแถวได้โดยไม่ต้องยกสแตก** ใช้กับตัวเลขในใบส่งมอบได้เลย
- **`e2e/playwright.config.js` ตั้ง `MIGRATION_CHECK=off` ให้ backend ของตัวเอง** และต้องเป็นอย่างนั้นต่อไป
- **`E2E_BACKEND_PORT=3110 E2E_FRONTEND_PORT=5300`** พอร์ต 5100 กับ 3100 ถูก Windows จองไว้
  อาการคือบอกว่ามีอะไรรันอยู่ทั้งที่ไม่มีอะไรฟัง
- **`npm test` ใน `e2e/` คือชุดเบราว์เซอร์ ส่วน unit ของ helper คือ `npm run test:support`** คนละอย่างกัน
- **อ้างสเปกด้วยชื่อเต็มเสมอ** `npx playwright test 22a` รัน `122a` ด้วย (#158) `python mutation/anchors.py`
  ตรวจข้อนี้ให้ทุกครั้ง
- **harness จะไม่ยอม `restore` ทับไฟล์ที่แก้หลัง `save`** ซึ่งถูกแล้ว (#126) **ระหว่างกวาด ต้นไม้เป็นของ
  harness** grep หรือ anchor check ตอนนั้นอ่านมัตแตนต์ ไม่ใช่โค้ด
- **อย่า grep ผลของการรันชุดทดสอบสด ๆ** ให้รันลงไฟล์แล้วค่อยอ่านไฟล์
- **คอนโซลเป็น cp874** พิมพ์ภาษาไทยหรือ ☑⚙◐☐ ออกทาง Bash แล้วพัง แต่**ส่งขึ้น GitHub ผ่าน
  `gh --body-file` ได้** (ทวนกลับด้วย `--json comments` ทุกครั้ง เพราะคอมเมนต์เป็นสาธารณะ)
