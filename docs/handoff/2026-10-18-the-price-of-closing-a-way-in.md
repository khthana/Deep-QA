## เรื่องที่จะกินเวลาถ้าไม่รู้ (gotchas)

- **โคลนอื่นยังมี `master` ที่ตายแล้ว** `git remote set-head origin -a && git branch -m master main
  && git branch --set-upstream-to=origin/main main`
- **ห้าม `git add -A`** (ตัวจำแนกอ่านว่าเป็นการ stage `.env` จริง) stage เป็น path เสมอ
- **trap ไม่ปิดทางของ `fill()`** — `fill()` โฟกัสช่องกรอกเอง ไม่ได้ tab และไม่ได้คลิกผ่านฉากคลุม
  ค่าถูกตั้งแล้วแม้โฟกัสจะถูกดึงกลับทันที จึงเป็นทางที่เครื่องมือมีและคนไม่มี (#47) — แถวของ `208a`
  ที่จอบัญชีผู้ใช้ผ่านทั้งก่อนและหลัง #217 โดยไม่ต้องแก้
- **การเติมกล่องคำถามหน้าคอนโทรล เป็นการเปลี่ยนวันที่ของข้ออ้างทุกใบที่พูดถึงทางเข้าของคอนโทรลนั้น**
  — grep ประโยค ไม่ใช่แค่การกด (#86, #130) สำมะโนของ #217 เจอ 313 บรรทัดใน 58 แฟ้ม
- **มัตแตนต์ที่ฆ่าแถวของแฟ้มอื่นคือราคาของข้อเสนอที่ถูกเลื่อน** วันที่ข้อเสนอถูกรับหรือถูกปฏิเสธ
  ต้องเปลี่ยนตัวมัตแตนต์ ไม่ใช่แค่ตัวเลขของมัน (#48 กับ #115 เป็นสองฝั่งของเรื่องเดียวกัน)
