## เรื่องที่ต้องรู้ก่อนเริ่ม (gotchas)

- **อย่ารัน `npm run format` และอย่ารัน `npx prettier --write` บนไฟล์ของ `frontend/`**
  prettier ที่ติดตั้งอยู่ใหม่กว่าสไตล์ที่คอมมิตไว้ มันเขียนทับบรรทัดที่มัตแตนต์ยึดอยู่ โดย diff
  อ่านเหมือนช่องว่าง (#189) ไฟล์ที่สะอาดอยู่แล้วก็ไม่ผ่านรุ่นนี้ คือ `Mainpage.js` กับ
  `CourseOutcomes.js` ถ้ารันไปแล้วให้ `git checkout --` ไฟล์นั้น แก้ด้วยมือใหม่ แล้วรัน
  `python mutation/anchors.py`

- **clone บนเครื่องอื่นยังมี `master` ที่ตาย** `origin/master` ไม่มีแล้ว clone ไหนที่ยังไม่ได้ซ่อมต้องรันมือ:

  ```bash
  git branch -m master main && git fetch origin --prune && git branch -u origin/main main
  ```

- **ชุดเต็มของ `e2e/` คือ 37.0–39.1 นาทีต่อรอบ (705 แถว)** การกวาดสิบสองรอบกินเวลาเจ็ดชั่วโมงครึ่ง
  รันเบื้องหลังแบบ **ไม่ต่อ `tail`** แล้วค่อยอ่านไฟล์ (ต่อ `tail` แล้วไฟล์เป็น 0 ไบต์จนจบ)
- **รอบที่ถูกสั่งหยุดอาจยังไม่หยุด (#146) และตัวบอกคือพอร์ต** ให้ไล่ต้นไม้ของโปรเซส
  (`taskkill //PID <pid> //T //F`) ไม่ใช่ฆ่าตัวที่ฟังพอร์ตตัวเดียว · **และห้ามแตะพอร์ต 3000/5000**
  — `grader-app-1` นั่งที่ 3000
- **ห้ามแก้ไฟล์ใน `frontend/` `e2e/` `mutation/` ระหว่างชุดทดสอบหรือ harness เดิน** คอมเมนต์
  บรรทัดเดียวก็ hot-reload กลางรอบและทำให้รอบนั้นใช้ไม่ได้ · และ probe ที่ลืมลบไว้ใน
  `e2e/tests/` จะถูกรันไปด้วย (รอบแรกของ #141 เสียไปด้วยเหตุนี้ `zz-141-*` สองไฟล์)
- **ก่อนเดินด้วยมือ ให้ `cd db && npm run migrate` เสมอ** (#159) — สแตกเดินคือ
  `docker start deep-core-postgres` (พอร์ต **5433**) · `cd db && npm run reset && npm run migrate && npm run seed`
  · backend พอร์ต 3000 · frontend พอร์ต 5000
- **`frontend/scripts/superseded-answers.js` เดินเฉพาะ `AwaitExpression`** จอที่วาดคำตอบด้วย
  `.then()` จึงอยู่นอกประชากรของสำมะโน เขียนด้วย `await` เสมอ เพราะเครื่องมือ ไม่ใช่เพราะสไตล์
- **สคริปต์แก้ไฟล์ต้องยึดกับข้อความ ASCII ไม่ใช่ข้อความไทย** และ **ภาษาไทยยาว ๆ ห้ามผ่าน heredoc**
  เขียนสคริปต์ลงไฟล์ก่อนแล้วรัน แล้ว**พิสูจน์อักษรด้วยการอ่านไดฟ์** ไม่ใช่ด้วยคอนโซล
- **`PGTZ` ไม่มีผลกับ `pg`** · การเปลี่ยน timezone ของเซสชันทำได้ที่เดียว คือ `-c timezone=...`
  ใน `options` ของพูลใน `db/pool.js` (#187)
- **`npm test` ของ backend คือ `node --test "test/*.test.js"`** · `node --test scripts/` ล้ม
  ต้องเป็นกลอบในคำพูด
- **`E2E_BACKEND_PORT=3400 E2E_FRONTEND_PORT=5310`** พอร์ต 5100 กับ 3100 ถูก Windows จองไว้
- **อ้างสเปกด้วยชื่อเต็มเสมอ** `npx playwright test 22a` รัน `122a` ด้วย (#158)
- **ระหว่างกวาด ต้นไม้เป็นของ harness** grep หรือ anchor check ตอนนั้นอ่านมัตแตนต์ ไม่ใช่โค้ด
- **อย่า grep ผลของการรันชุดทดสอบสด ๆ** ให้รันลงไฟล์แล้วค่อยอ่านไฟล์
- **คอนโซลเป็น cp874** พิมพ์ภาษาไทยหรือ ☑⚙◐☐ ออกทาง Bash แล้วพัง แต่ส่งขึ้น GitHub ผ่าน
  `gh --body-file` ได้
