## #35 หลักฐานการประเมิน

ตั๋วนี้มีอยู่เพราะข้อบกพร่องความปลอดภัยสองข้อพอ ๆ กับเพราะตัวฟีเจอร์

**ตรวจชนิดไฟล์ที่ไบต์** `looksLikePdf` อ่านห้าไบต์แรก แถวที่มีความหมายคืออัปโหลดไบต์ PNG ที่ชื่อ
`brief.pdf` และประกาศตัวเป็น `application/pdf` เพราะสองอย่างหลังผู้อัปโหลดเขียนเองได้

**ไม่มี static mount เลย** `GET /api/evidence/:id/file` อ่านแถว ถามว่าผู้เรียกคนนี้เปิดได้ไหม แล้วจึงอ่านไบต์
สิทธิ์มีสองคำถาม ตอบผ่านข้อไหนก็พอ — อาจารย์ผ่าน `sectionOf` ส่วนกรรมการ/ผู้ประเมินผ่านเส้นทาง CLO
ของหลักสูตรที่อ่านได้ ซึ่งเป็นเส้นเดียวกับที่ drill-down ของ #42 เดินลงมา **บันทึกใน ADR-0002**

**ที่ยังไม่มีใครตัดสิน** ไบต์ของไฟล์ที่ถูกแทนที่ยังอยู่บนดิสก์ แถวชี้ไปไฟล์ใหม่แล้ว เข้าถึงผ่าน API ไม่ได้
แต่ยังกินที่และอยู่ในสำรองข้อมูล — การลบทิ้งขัดกับเจตนา soft delete ของ migration 0003

## #36 ผลลัพธ์การเรียนรู้รายวิชา

**เลขคณิตไม่ใช่ของใหม่** `columnOf` กับ `summaryOf` ย้ายจาก route ของ #38 เข้า `lib/attainment.js`
ตอนที่ #36 เป็นผู้ใช้รายที่สอง ซึ่งเป็นจุดที่ repo นี้กำหนดให้แยก

**สองการตัดสินใจที่ผู้ใช้เลือกก่อนเขียนโค้ด**

1. ปีก่อนหน้า = **ทุกตอนเรียนของวิชานั้นในปีนั้น รวบเป็นตัวเลขเดียว** ไม่ใช่เฉพาะห้องที่ผู้สอนคนนี้สอน
2. เสนอเฉพาะ **ปีที่ชุดเลข CLO ตรงกันเป๊ะ** ปีที่ไม่ตรงถูกปฏิเสธเป็นประโยค ไม่ใช่ถูกตัดทิ้งเงียบ ๆ

ข้อแรกกว้างกว่าด่านของตอนเรียนฐาน จึง**บันทึกใน ADR-0002** และถูกจำกัดด้วย*รูปร่างของคำตอบ*:
ไม่มี `section_id` ไม่มีเลขตอนเรียน ไม่มีผู้สอน ไม่มีนักศึกษา และไม่มีพารามิเตอร์ที่เอ่ยถึงตอนเรียนของปีก่อนได้

**กราฟเรดาร์เขียนเป็น SVG ด้วยมือ ไม่ได้เพิ่ม dependency** เหตุผลที่ตัดสินคือ canvas เป็นรูปภาพ
ซึ่งทั้ง screen reader และ browser seam อ่านไม่ได้ทั้งคู่ — ผู้อ่านสองรายที่ repo นี้มีจริง
ทุกจุดเป็น element ที่มี `<title>` และตารางข้างล่างมีตัวเลขทุกตัวที่กราฟวาด

**ช่องว่างไม่ใช่ศูนย์ บนกราฟด้วย** รูปหลายเหลี่ยมต้องการจุดยอดบนทุกแกน และจุดยอดที่ชัดที่สุดสำหรับ
*ไม่มีข้อมูล* อยู่ตรงกลางวง ซึ่งเป็นที่เดียวกับคะแนนศูนย์พอดี เส้นจึง**ขาดตอน**แทน

## กับดักที่บันทึกใหม่รอบนี้

### พอร์ตที่ listening ไม่ได้แปลว่าเซิร์ฟเวอร์ยังตอบ

CRA dev server ที่พอร์ต 5000 **ตายทั้งที่ยัง bind พอร์ตอยู่** `netstat` เห็นว่ายัง listen `curl` ค้าง
แทนที่จะโดนปฏิเสธ และไม่มีสัญญาณอื่นเลย ผลคือ `navigate` ของส่วนขยาย Chrome ตอบว่า **สำเร็จ**
เพราะรับคำสั่งได้ แต่ไม่มีหน้าโหลด — `javascript_tool` กับการถ่ายภาพจึง time out หรือบอกว่า
*Can't interact with browser-internal or unparseable URLs*

**พอส่วนขยายเริ่มทำตัวแปลก ให้ `curl --max-time 5 http://localhost:5000/` ก่อนโทษเบราว์เซอร์**
รอบนี้เสียเวลาไปมาก และวินิจฉัยผิดสองรอบ (สงสัยโค้ดหน้าจอก่อน แล้วโทษส่วนขยาย) ผู้ใช้เป็นคนทักถูก

### อีเมลของ seed เป็น `@kmitl.ac.th` ไม่ใช่ `@deep.local`

กรอกผิดทำให้ผู้ใช้พิมพ์รหัสผ่านสองรอบใส่บัญชีที่ไม่มีอยู่ และหน้าจอไม่ได้บอกสาเหตุที่แท้จริง
ซึ่งตรงกับ [#97](https://github.com/khthana/Deep-QA/issues/97) พอดี **อ่านที่อยู่จาก
`e2e/support/accounts.js` อย่าพิมพ์จากความจำ**

### หลังผู้ใช้บอกว่าเข้าระบบแล้ว ให้ยืนยันก่อนสั่งอะไรต่อ

`navigate` คือการโหลดหน้าใหม่ทั้งหน้า ถ้าสั่งทันทีที่ผู้ใช้บอก มันจะแข่งกับการเข้าระบบและเด้งกลับมาที่ฟอร์ม
**อ่าน `location.href` กับดูว่าช่องรหัสผ่านหายไปแล้วก่อน**

### หน้าต่าง Chrome ที่ถูกย่อเก็บ ปรับขนาดไม่ได้

`resize_window` ตอบว่าสำเร็จแต่ `innerWidth` ไม่ขยับ อาการที่บอกได้คือ **`window.outerWidth` อ่านได้ `0`**
และภาพถ่ายออกมามืดทั้งหน้า (ทรานซิชัน fade-in ไม่เดินเมื่อ `document.hidden` เป็น true)
ต้องให้ผู้ใช้คลิกหน้าต่างขึ้นมาข้างหน้าก่อน

### ปุ่มยุบ sidebar หาโดยตำแหน่ง ไม่ใช่โดยป้าย

ที่จอแคบ sidebar ทับเนื้อหา ปุ่มยุบเป็นวงกลมไม่มี `aria-label` — หาโดยขนาดกับตำแหน่ง
(`width` ราว 36 และ `x` ระหว่าง 250–400) ระวังอย่าไปโดนปุ่ม avatar ที่มุมขวาบน ซึ่งเปิดเมนูผู้ใช้บังกราฟ
