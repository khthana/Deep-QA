## #140 (ปิด, `263a8dc`) — handler ที่สั่งโหลดใหม่ ถามว่าจอยังอยู่ที่เดิมไหม

- **ทุก handler ส่ง `() => onScreen.current === load`** และค่าตั้งต้น `isCurrent = () => true` ถูก**เอาออก**จาก
  ยี่สิบสองไฟล์ ผู้เรียกที่ลืมธงจึงโยน error ไม่ได้วาดเงียบ ๆ `load` ถูกสร้างใหม่พอดีเมื่อสิ่งที่รายการขอเปลี่ยน
  (`report` memoise ด้วย `[]`) การเทียบเดียวจึงใช้ได้ทั้งจอที่ขอสองอย่างและห้าอย่าง
- **ตั๋วนับสิบเอ็ดจอ สามสิบสองจุด วัดได้สิบเก้าจอ ห้าสิบสองจุด** แบ่งเป็นสองตระกูล:
  - **เก้าจอ สามสิบเอ็ดจุด** มีตัวแบ่งหน้าบนจอ แต่ละจุดมีแถวใน `e2e/tests/140a-superseded-handler-reload.spec.js`
    (32 แถว — `SubjectStudents.reload` มีผู้เรียกสองทาง) และมัตแตนต์ `load(() => true)` ของตัวเองใน
    `mutation/140-superseded-handler-reload.py` ทุกตัวล้มแถวของตัวเองที่ `toEqual` แถว ⚙ อยู่บนใบ
    `11` `14` `15` `16` `17` `18` `21` `23` `25` ทะเบียนอยู่ที่ `57-pager.md` §handler ปิดแล้ว — #140

    ตัวติดตามคือ **#141** — คอมเมนต์ที่ https://github.com/khthana/Deep-QA/issues/141#issuecomment-5715229103
    มีตารางต่อไฟล์ต่อบรรทัด **#141 ตอนนี้ถือสามสิบเจ็ดจุด** (16 ของ #133 + 21 ของ #140) บนสิบหกใบ

- **การเปลี่ยนลายเซ็นของฟังก์ชันไปถึงทุกมัตแตนต์ที่*เขียน*การเรียกมัน** — `25:addstaysonpage` และ

  (`16:M9` `21:staleafterasave` `23:nolanding` `savenoreload` ของ `27`–`31`) ก็ถูกเล็งใหม่และกวาดซ้ำ

- **`page.unroute` เทียบ matcher ด้วย `===`** — ฟังก์ชันใหม่ที่หน้าตาเหมือนกันไม่ลบ route อะไรเลย ต้องส่งฟังก์ชันเดียวกัน

## ตั๋วใหม่ #144 — ตัวกรองบนหกจอ

guard ของ #140 ครอบตัวกรองโดยโครงสร้าง แต่ทุกแถวของ `140a` กดตัวแบ่งหน้า และมัตแตนต์ที่จุดเรียกทำลาย guard ของ
ทุกตัวควบคุมพร้อมกัน **สิบตัวควบคุมบนหกจอ** (`Users` ช่องค้นหา·บทบาท·สถานะ · `Subjects` ภาควิชา ·
`Students` `ProgramSubjects` `Rubrics` หลักสูตร · `Offerings` หลักสูตร·ปีการศึกษา·ภาคเรียน) จึงไม่มีหลักฐานของตัวเอง
**ช่องค้นหาของ `Users` ถูกพบตอนวัดเพื่อเปิดตั๋ว** — แถว ☐ บนใบ `11` เอ่ยถึงแค่บทบาทกับสถานะ

ตั๋วเสนอมัตแตนต์ที่ **ref effect** แทนที่จุดเรียก: dependency ของ `onScreen.current = load` ขาดตัวกรองตัวเดียว
(เช่น `Users.js` `[load]` → `[page, filters.role, filters.status]`) **เป็นการอ่านโค้ด ยังไม่ได้กวาด**
แถว ☐ ทั้งหกชี้ไป #144 แล้ว (`27d86c4`)

## Gotchas ที่ยังต้องพก

ยกมาทั้งชุดจากใบก่อนหน้า ยังใช้ได้ทุกข้อ และเพิ่มจากรอบนี้

- `git clone` ที่ทำไว้ก่อนเปลี่ยนชื่อ branch ยังชี้ `master` ที่ตายแล้ว แก้ด้วย
  `git remote set-head origin -a && git branch -m master main && git branch -u origin/main`
- **`anchors.py` อ่าน anchor ไม่ได้อ่านสิ่งที่มัตแตนต์แทนเข้าไป** — เมื่อเปลี่ยนลายเซ็นของฟังก์ชัน ให้ grep สตริงแทนที่
  ในทุกไฟล์มัตแตนต์ด้วย ไม่ใช่แค่รัน `anchors.py`
- **`page.unroute(matcher)` ต้องได้ฟังก์ชันตัวเดียวกับที่ส่งให้ `page.route`** — Playwright เทียบด้วย `===`
  และ handler ที่หน่วงคำตอบต้องกลืน error ของ `route.continue()` เมื่อแถวจบและปิดหน้าไปแล้ว
- **สคริปต์นับเครื่องหมายต้องตรวจว่าช่องสุดท้ายยาวหนึ่งตัวอักษร** — ใน Python `'' in 'marks'` เป็นจริง
  ช่องว่างท้ายแถวจึงถูกนับเป็นเครื่องหมาย (หรือโยน `KeyError`) นอกจากกฎเดิมว่าอ่านช่องสุดท้าย*และ*ต้องขึ้นต้นด้วยเครื่องหมาย
- **การกวาดทีละจอ ไม่ใช่ทั้งชุด** — `139a` / `140a` ตั้งชื่อแถวด้วย `(ชื่อไฟล์.js)` ใช้ `--grep "\(Offerings\.js\)"`
  กับ spec ของจอนั้น รัน baseline ก่อน และเมื่อหน้ายังไม่ได้ commit ให้เทียบ **sha1** ของหน้าหลัง `restore` ทุกตัว
- **แถว ☐ ที่ชี้ตั๋วที่กำลังจะปิด ต้องชี้ตั๋วที่รับช่วงในวันที่เปิดมัน** — ไม่อย่างนั้นลูกศรชี้ไปตั๋วที่ปิดแล้ว
- **ตั๋วบน tracker อ้าง `ไฟล์:บรรทัด` — การเติมบรรทัดในคอมเมนต์ของไฟล์เดียวกันทำให้ตั๋วผิดทันที**
  จัดบรรทัดใหม่ให้จำนวนบรรทัดเท่าเดิม และตรวจด้วย `sed -n '<n>p'` หลังแก้ทุกครั้ง อ้าง SHA คู่กับเลขบรรทัด
- **`prettier` ไม่ใช่ dependency ของ repo** — อย่าถือผลของ `npx prettier --check` เป็นมาตรฐาน
