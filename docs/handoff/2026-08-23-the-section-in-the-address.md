## 6. กับดักที่จะกัด (เฉพาะที่เปลี่ยนจากฉบับก่อน)

- **`db/term.js` ทำให้ seed เดินตามนาฬิกา** มิ.ย.–ต.ค. = ภาคต้น (1) พ.ย.–พ.ค. = ภาคปลาย (2)
  ปีการศึกษาขึ้นใหม่เดือนมิถุนายน **ฐานข้อมูลที่ seed ไว้ก่อนวันที่ 23 ส.ค. จึงเก่าเสมอ**
  อาการคือหน้าจอว่างโดยไม่มีข้อผิดพลาดใด ๆ reset ก่อนสงสัย
- **ปีที่เข้าศึกษาของ cohort ใน seed เป็นค่าคงโดยตั้งใจ** ไม่ใช่ของลืม
  `backend/test/students.test.js` อ่านรหัส `66010001` และ `65010001` กลับมาตรง ๆ
  เหตุผลเต็มเขียนไว้ที่คอมเมนต์ของ `COHORTS` ใน `db/seed.js`
- **อย่าใส่ mutant ขณะที่ dev frontend หรือการรันกำลังทำงานอยู่** CRA คอมไพล์สิ่งที่อยู่บนดิสก์
  ณ ขณะนั้น มิวแตนต์ที่ใส่กลางการรันคือผลลัพธ์เกี่ยวกับอะไรก็ไม่รู้
- **ชุดเบราว์เซอร์เต็มใช้เวลา ~12–13 นาทีตอนนี้ (114 แถว)** รันเป็น background task
  ถ้าการรันถูก timeout กลางคัน **server จะค้างที่พอร์ต 3100/5100** รอบถัดไปจะขึ้นว่า
  `already used` — ปิดด้วย `Get-NetTCPConnection -LocalPort 3100,5100 -State Listen` แล้ว `Stop-Process -Force`
- **ถ้า loop ของมิวแตนต์ถูกตัดกลางคัน ต้นไม้จะค้างอยู่ในสภาพ mutate**
  `python mutation/<file>.py restore` แล้วดู `git status` ว่าไม่มีไฟล์ใน `backend/` หรือ `frontend/` เหลืออยู่
- **A fresh clone lands on a dead `master`.** Run, verbatim:
  `git branch -m master main && git fetch origin --prune && git branch -u origin/main main`
