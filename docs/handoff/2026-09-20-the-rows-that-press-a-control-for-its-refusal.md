## Gotchas ที่ยังต้องพก

ยกมาทั้งชุดจากใบก่อนหน้า ยังใช้ได้ทุกข้อ และเพิ่มจากรอบนี้ (สามข้อแรก)

- **`FILES` ที่เขียนว่า *ใบนี้ไม่ชนกับใคร* เป็นข้ออ้างที่หมดอายุได้เหมือนตัวเลข** — `121` เขียนไว้อย่างนั้น
  จนกระทั่ง `130` ถือ `GrantsPanel.js` ด้วย ตรวจด้วยสคริปต์สำมะโนใน `mutation/README.md` ไม่ใช่ด้วยการอ่านหัวไฟล์
- **การกวาดมัตแตนต์ที่อยู่บนโค้ดของหน้าจอที่ใบอื่นก็วัด ต้องรันสเปกของใบอื่นด้วย** — `12a` ไฟล์เดียวรายงาน
  `everyrowisdead` ได้ 1 ซึ่งเป็นขอบล่าง ของจริงคือ 3 เมื่อรัน `111a` กับ `121a` ด้วย
- **เพิ่มบัญชีลง seed ต้องไล่ทุกที่ที่นับจำนวนบัญชีไว้** — `README.md` (ตารางคือรายการเอง จึงนับต่อ) และ
  `11-user-accounts.md` (ตัวเลขมีวันที่กำกับ) `docs/04` ไม่ต้องแตะ เพราะเป็นเอกสารของสิ่งที่ส่งมอบ ไม่ใช่ของ seed วันนี้
- `git clone` ที่ทำไว้ก่อนเปลี่ยนชื่อ branch ยังชี้ `master` ที่ตายแล้ว แก้ด้วย
  `git remote set-head origin -a && git branch -m master main && git branch -u origin/main`
- **ข้อความ commit ห้ามมีคำปิดตั๋ว** (`close: #N` ก็ปิด) ใช้ `Refs #N` และตรวจด้วย
  `grep -niE '(clos|fix|resolv)[a-z]*:? +#[0-9]'` ก่อน commit
- **`gh issue close` ไม่มี `--comment-file`** ใช้ `gh issue comment <n> --body-file <f>` แล้วตามด้วย
  `gh issue close <n> --reason completed`
- **อย่าแก้ไฟล์ที่อยู่ใน `FILES` ของไฟล์มัตแตนต์ ขณะที่ sub-agent (เช่น reviewer) อาจกำลังใส่มัตแตนต์**
  `restore` จะปฏิเสธ (#126) และมัตแตนต์ค้างในต้นไม้ บอก reviewer ว่าห้ามรัน harness
- **แท็บ Chrome ที่ถูกซ่อนรับการกดปุ่มในช่องวันที่ไม่ได้ และภาพหน้าจอเลื่อนจากพิกัดจริง**
- **มัตแตนต์ในโค้ดที่ใช้ร่วม (`backend/lib/`) ต้องกวาดกับชุด backend ทั้งชุด**

- **มัตแตนต์แบบหลายจุดคือ list ของ `(key, old, new)`** ไม่ใช่ `(key, [(old, new)])`
- **`page.unroute(matcher)` ต้องได้ฟังก์ชันตัวเดียวกับที่ส่งให้ `page.route`**
- **สคริปต์นับเครื่องหมายต้องตรวจว่าช่องสุดท้ายยาวหนึ่งตัวอักษร** — ใน Python `'' in 'marks'` เป็นจริง

- `node server.js` ไม่มี reload — บันซ์ backend ก่อนเดินทุกครั้ง
- TaskStop ปิด shell แต่ไม่ปิดลูกของมัน — ฆ่าเฉพาะ PID บน 3100/5300
- **อย่ากวาดมัตแตนต์ระหว่างที่ชุด e2e กำลังรัน** และ **เดินด้วยมือก่อนกวาดและก่อนรันชุดเต็ม**
- **docstring ในไฟล์มัตแตนต์ที่อ้าง regexp ต้องเป็น raw string** (`r"""`)
- **spec ที่รันแบบ `serial` รายงาน kill ต่ำกว่าจริง** (`12a` `16a` `21a` `23a`) — วัดทีละแถวด้วย `--grep`
- **`node --test` นับ suite แม่ใน `# fail` และเทสต์ระดับบนสุดของไฟล์มี `not ok` ที่ไม่เยื้อง**
- **การรอที่เขียนเพื่อจังหวะเวลา ต้องมี timeout ที่ยอมให้หมดได้**
- **ค้นบน tracker ก่อนเปิดตั๋ว** (`gh issue list --state all --search "<ชื่อ spec หรือไฟล์>"`)
- **`npx eslint` ใน `backend/` และ `e2e/` ออก exit 2 เพราะไม่มี config** ใช้ `node --check` ที่นั่น
