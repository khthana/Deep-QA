## เหตุผลของคำสั่งเป็นข้ออ้าง และเป็นข้ออ้างที่วัดไม่ได้

*ระบบนี้ไม่มีคนพิการใช้* เป็นข้ออ้างเรื่องคนที่ใช้ระบบวันนี้ ไม่ใช่เรื่องสิ่งที่ระบบทำได้ #257 ขอให้
วัดเหตุผลของเจ้าของงานแล้วเอาผลกลับไปที่เจ้าของงาน ข้อนี้**วัดไม่ได้** — ไม่มีเครื่องมือในคลังนี้ที่
อ่านมันได้ และมันเป็นข้อมูลของคน จึงไม่ใช่สิ่งที่ควรไปถาม สิ่งที่จ่ายแทนคือเขียนว่ามันเป็นข้ออ้างที่มี
วันที่ และเขียนเงื่อนไขที่เหลือสองทางไว้ข้าง ๆ คือ **มีคนใช้ระบบนี้ด้วยหู** หรือ **เส้นของกฎหมาย
(มาตรา 20 (6) กับกฎกระทรวงปี 2554) ถูกบังคับใช้กับระบบภายใน** — ลงวันที่ไว้ ไม่ได้ลบ (#54)

## สิ่งที่จะเสียเวลาถ้าไม่รู้

- **สาขาหลักชื่อ `main`** โคลนเก่าที่ยังชี้ `master` แก้ด้วย
  `git remote set-head origin -a && git branch -u origin/main main`
- **อย่าพิมพ์ชื่อเกณฑ์ภาษาไทยจากความจำลงไปใน anchor ของสคริปต์** วันนี้เสียเวลาไปหนึ่งรอบเพราะ
  เขียน `ครึ่ง` ด้วย U+0E35 แทน U+0E36 สคริปต์ตอบ `count 0` ไม่ใช่ error — อ่านข้อความออกจาก
  แฟ้มแล้วใช้ตัวนั้น (#231 ชนิดเดียวกัน)
- **อย่ารันข้อความไทยผ่าน heredoc ของ Bash** และอย่าพิมพ์ไทยออกคอนโซล ใช้เครื่องมืออ่านแฟ้ม
- **หน้าต่างที่ขยายเต็มจอย่อไม่ได้ และ popup ก็ไม่ใช่ทางออก** `resize_window` ตอบว่าสำเร็จ
  ขณะที่ `innerWidth` ไม่ขยับเลย ซึ่งเป็นอาการเดียวที่มันแสดง ส่วน `window.open` ที่ขอขนาด
  เองถูกบล็อกเพราะไม่ได้เกิดจากการกดของคน ทางเดียวคือให้คนกด Win+ลูกศรลง ให้หน้าต่างลอยก่อน
- **อย่าแตะ `DEEP-QA-BACKEND/` หรือ `_local/` ใน `git add`** และอย่าใช้ `git add -A`
