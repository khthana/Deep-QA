## เรื่องที่จะกินเวลาถ้าไม่รู้ (gotchas)

- **clone อื่นยังมี `master` ที่ตายแล้ว** ปลายทางเปลี่ยนเป็น `main` แล้ว clone เก่าต้องแก้มือ:
  `git branch -m master main && git fetch origin && git branch -u origin/main main && git remote set-head origin -a`
- **`git add -A` ถูกปฏิเสธโดยตัวจัดประเภทของโหมดอัตโนมัติ** เพราะรีโปมี `DEEP-QA-BACKEND/` กับ
  `_local/` อยู่ข้างใน **stage ด้วยพาธชัดเจนเสมอ** และห้าม `git add` อะไรใต้สองที่นั้น
- **`gh issue create` ถูก classifier ปฏิเสธ** ขณะที่ `gh issue comment` `gh issue close` และ
  `git push` ผ่านหมด — stage ร่างไว้ใน `_local/github/` แล้วส่งคำสั่งเดียวให้เจ้าของงานรันเอง
- **การกวาดบอกไม่ได้ว่าการแก้ของคุณทำแถวไหนพัง** ชุดเต็มคือสิ่งที่บอก (#83) — ถ้าการแก้แตะยามที่
  ตั๋วอื่นก็ถืออยู่ ให้รันแฟ้มของตั๋วนั้นด้วยในรอบเดียวกัน ไม่ใช่แค่แฟ้มของตัวเอง · และ **การผ่ายาม
  ออกเป็นสองท่อน ต้องตามด้วยการกวาดซ้ำ ไม่ใช่แค่ `anchors.py`** (#203 รอบนี้มาเก็บค่าตัวอีกตัว)
- **heredoc กินแบ็กสแลช** `\\n` ในสคริปต์ที่เขียนด้วย heredoc กลายเป็นบรรทัดใหม่จริงและทำให้
  แฟ้มมัตแตนต์พัง (เกิดขึ้นรอบนี้ **สองครั้ง**) — เขียนสคริปต์ด้วยเครื่องมือเขียนไฟล์ และ
  **ยึดสมอบน ASCII** ที่ไม่ซ้ำ
- **`countmarks3.py` ต้องการพาธปลายทางเป็นอาร์กิวเมนต์** ไม่งั้นมันพิมพ์ ☑⚙◐☐ ลงคอนโซล cp874
  แล้วตาย
- **`prettier --check` ไม่ใช่ประตูที่ใช้ได้กับแฟ้มหน้าจอเหล่านี้** · **อย่ารัน `npm run format` หรือ
  `npx prettier --write`** (#189)
- **พอร์ต 3100/5100 ของ `e2e/` ถูก Windows จองไว้** อ่าน
  `netsh interface ipv4 show excludedportrange protocol=tcp` **ทุกครั้ง** แล้วเลือกจากนอกช่วง
  อย่ายกพอร์ตจากใบนี้ไปใช้ (รอบนี้ใช้ 3400/5310)
- **คอนเทนเนอร์ `deep-core-postgres` ต้องสตาร์ตหลังรีบูต** อาการคือ webServer timeout ไม่ใช่
  ข้อผิดพลาดของฐานข้อมูล
- **คอนโซลเป็น cp874** อย่าพิมพ์ไทยหรือ ☑⚙◐☐ ผ่าน Bash ใช้ Read/Grep หรือ redirect ลงไฟล์แล้ว
  Read หรือ `PYTHONIOENCODING=utf-8` · ส่งไทยขึ้น GitHub ด้วย `--body-file` กับพาธแบบ Windows
  และ `MSYS_NO_PATHCONV=1` · `gh issue close` **ไม่มี** `--comment-file` · ข้อความคอมมิตภาษาไทย
  ส่งด้วย `git commit -F <file>`
- **ห้ามแก้ไฟล์ใน `frontend/`, `e2e/` หรือ `mutation/` ขณะชุดทดสอบหรือฮาร์เนสรัน** และห้าม grep
  ต้นไม้ขณะกวาด · แก้เอกสารล้วนระหว่างชุดทดสอบรันได้
- **ไทยที่พิมพ์ด้วย codepoint ต้องสแกนซ้ำ** ตัวที่จับได้คือการตรวจคลังคำของรีโปเอง ไม่ใช่ตา
