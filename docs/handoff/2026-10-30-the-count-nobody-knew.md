## สิ่งที่จะเสียเวลาถ้าไม่รู้

- **`powershell -File … > out.txt` เขียนไฟล์เป็น UTF-16LE** ฉะนั้น `cat` `grep` `head` อ่านมันเป็น
  ขยะ และ python ที่เปิดด้วย `encoding='utf-8'` ได้สตริงที่ regex หาอะไรไม่เจอเลย — **ตัวบอกคือ
  ผลว่าง ไม่ใช่ error** · อ่านด้วย `open(p,'rb').read().decode('utf-16')` หรือดู BOM `\xff\xfe` ก่อน
- **คอนเทนเนอร์ `deep-core-postgres` ไม่ขึ้นเองหลังเครื่องรีบูต** และอาการคือ webServer timeout
  ไม่ใช่ error ของฐานข้อมูล · `docker start deep-core-postgres` ก่อนรันอะไร
- **พอร์ตที่ Hyper-V จองเปลี่ยนทุกครั้งที่รีบูต** — 30 ต.ค. 2569 ช่วงที่จองคือ 1061–1560,
  5357, 6533–7032 และ 50000–50060 ฉะนั้น 3100/5100 ใช้ได้ตามปกติ และไม่ต้องตั้ง
  `E2E_BACKEND_PORT` · **อ่าน `netsh interface ipv4 show excludedportrange protocol=tcp` ทุกครั้ง
  อย่ายกพอร์ตจากใบส่งมอบมาใช้**
- **ข้ออื่นทั้งหมดของหมวดนี้ในใบ `2026-10-29-the-row-outside-the-filter.md` ยังใช้ได้** — ชุด
  เบราว์เซอร์ ~51 นาทีและชุดที่ตายกลางทางอ่านเหมือนชุดสะอาด · ห้ามแก้ `frontend/src` `e2e/`

  ก้อนใหญ่ · เขียนสคริปต์แก้ไฟล์ลงแฟ้ม อย่าใช้ heredoc (`\uXXXX` ถูกถอดก่อน ตัวบอกคือ count 0) ·
