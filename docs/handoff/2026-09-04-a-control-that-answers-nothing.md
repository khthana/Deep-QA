## สามข้อที่ควรอ่านก่อนทำอะไรต่อ

### หนึ่ง — ตัวควบคุมที่ตอบว่าไม่มีอะไร คือสิ่งที่เทสต์มองไม่เห็นโดยธรรมชาติ

การเดินของ #40 เจอแผ่นพับรูบริกที่ขึ้นบนรายวิชาซึ่งยังไม่ได้กำหนดผลการเรียนรู้เลย กดแล้วเปิดออกมา
เป็นกล่องเปล่า แผ่นพับถูกวาดนอกโซ่สามสถานะจึงขึ้นทั้งสามสถานะ

ที่ควรจำไม่ใช่บั๊ก แต่คือ**เหตุที่ไม่มี assertion ไหนจับได้**: ทุกแถวอัตโนมัติถามว่าแผ่นพับ*ทำงานไหม*
และมันทำงานสมบูรณ์แบบ — กับความว่างเปล่า **เทสต์ถามได้ว่าตัวควบคุมตอบสนองไหม มีแต่คนที่ถามว่า
การตอบสนองนั้นควรมีอยู่ตั้งแต่แรกไหม** เป็นครั้งที่สองต่อจากการเดินของ #43

เวลาเขียนหน้าจอที่มีหลายสถานะ ให้ถามทุกชิ้นที่วาดอยู่**นอก**โซ่สถานะว่ามันควรอยู่ในทุกสถานะจริงไหม

### สอง — ตัวจัดรูปแบบเป็นเรื่องของชุดมัตแตนต์ด้วย

สมอของมัตแตนต์คือสตริงพร้อมย่อหน้า การรัน prettier กับ `CloAssessment.js` (ซึ่งเป็นไฟล์เดียว
ในโปรเจกต์ที่หลุดไปโดยไม่ผ่าน) ขยับย่อหน้าในตัวตารางและทำให้มัตแตนต์สองตัวหลุดสมอเงียบ ๆ

**รัน `npx prettier --check src` ก่อนเขียนไฟล์มัตแตนต์ ไม่ใช่หลัง** และมีสคริปต์สั้น ๆ ที่ import
ไฟล์มัตแตนต์แล้วเช็คว่าสมอทุกตัวยังหาเจอในซอร์ส ใช้เวลาวินาทีเดียวและจับได้ทันที:

```python
import io, importlib.util, sys
spec = importlib.util.spec_from_file_location('m', 'mutation/40-clo-assessment.py')
m = importlib.util.module_from_spec(spec); spec.loader.exec_module(m)
src = {k: io.open(v, encoding='utf-8').read() for k, v in m.FILES.items()}
print([n for n, (f, old, new) in m.MUTANTS.items() if old not in src[f]])
```

### สาม — ⚙ ที่ไม่ได้มาจริง: ห้าตั๋วติดกัน และคราวนี้มีชนิดใหม่

#42 · #36 · #37 · #39 · #40 ทุกใบมีแถว ⚙ ที่ไม่มีมัตแตนต์ค้ำ และทุกใบจับได้ด้วยรีวิวของตัวเอง
ไม่ใช่ของใบที่เขียนมัน กฎเดิมยังใช้: ถ้าตอบไม่ได้ว่า *แถวนี้เอ่ยชื่อ spec ไฟล์ไหน แถวที่เท่าไร
มัตแตนต์ตัวไหนค้ำ* มันคือ ☑ ไม่ใช่ ⚙

**สิ่งที่ #40 เพิ่มเข้ามาคือชนิดที่สอง** แถวชื่อไฟล์ PDF ไม่ได้แค่ขาดมัตแตนต์ แต่ assertion ที่มี
ยัง**อ่อนกว่าที่แถวอ้าง** — เขียนว่า `assessment-.+\.pdf` ใต้แถวที่บอกว่าชื่อไฟล์ต้องระบุรหัสวิชา
เลขตอนเรียน และปี ชื่อที่ไม่มีอะไรเลยสักอย่างก็ผ่าน **การมี assertion ไม่เท่ากับการพิสูจน์**
ตอนไล่แถว ⚙ ให้เปิดอ่าน assertion จริง ไม่ใช่แค่ยืนยันว่ามันมีอยู่

## กับดักของเครื่องมือที่เจอรอบนี้

- **`resize_window` เงียบ ๆ ไม่ทำงานกับหน้าต่างที่ maximise อยู่** ตอบว่าสำเร็จแต่ viewport ไม่ขยับ
  อ่าน `window.innerWidth` เสมอ อย่าเชื่อคำตอบของเครื่องมือ พอหน้าต่างลอยอิสระแล้วมันทำงานทันที
- **`Win + ←` บนเครื่องสองจอย้ายหน้าต่างไปอีกจอ ไม่ใช่ย่อครึ่ง** เช็ค `window.screenX` ถ้าค่าติดลบ
  คือย้ายจอไปแล้ว
- **หน้าต่างที่ย่อลง taskbar ทำให้ screenshot ค้างจนหมดเวลา** `document.hidden` เป็นจริงและ
  `outerWidth` เหลือ 160 — วัดด้วย JS แล้วขอให้คนเปิดหน้าต่างขึ้นมา
- **เซสชันหมดอายุกลางการเดิน** (#99) เกิดสองครั้งในรอบนี้ กรอกอีเมลไว้ให้แล้วขอให้ผู้ใช้ใส่รหัสผ่านเอง
