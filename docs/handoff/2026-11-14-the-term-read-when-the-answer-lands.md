## สิ่งที่จะเสียเวลาถ้าไม่รู้

- **เลขของ 14 พ.ย.** `npm run census` สิบสามตัว `problems 0` · `npm run census:test` **256 ผ่าน 0 ล้ม** ·
  `python mutation/anchors.py` `problems 0` ทุกหัวข้อ · มัตแตนต์ **1316** ตัว
- **ชุด e2e ล่าสุดคือ 1045 แถว 1.0 ชม.** (14 พ.ย.) อ่านเลข **ล้ม** ไม่ใช่เลขผ่าน
- **`StudentGroups.js` มีชื่อ `typed` สองความหมายเกือบได้** — `create` ใช้ `typed` เป็นสตริงชื่อกลุ่ม ref ของคำค้นจึงชื่อ

  แทนที่ กลุ่มงานพูดประโยคของคำค้นตอนคำตอบกลับ นี่คือคำตอบของเจ้าของงาน ไม่ใช่ความไม่สม่ำเสมอที่ต้องแก้
- **`.env.example` มี client ID และ secret จริงของ Google OAuth ค้างอยู่โดยไม่ commit** — stage ตาม path เสมอ
  ถ้าหลุดขึ้น repo สาธารณะ ให้ลบค่าออกแล้วเปลี่ยน secret
- **harness ไม่มีคำสั่ง `apply`** · **`& npx` ตายใน PowerShell** · **ห้ามเดินครึ่งที่ต้องใช้หู** (§#265)
