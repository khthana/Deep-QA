## สิ่งที่ลงไปของ #156

- **`frontend/src/components/SidebarItem.js` บรรทัดเดียว** กล่องไอคอนของรายการย่อย
  `h-5 w-5 … text-[18px]` → `h-4 w-4 … text-[16px]` พร้อมคอมเมนต์ที่บอกว่าทำไมเป็น 16 ไม่ใช่ 20
  และบอกว่าข้อที่สองถูกตอบว่าปล่อยไว้
- **ไอคอนในคอนฟิกทุกตัวประกาศเปล่า** (`icon: <HiOutlineScale />` ไม่มี `size` ไม่มี `className`
  ที่ไหนใน `components/SidebarItem/*.js`) จึงวาดที่ `1em` ของกล่อง — `text-[16px]` ย่อ**รูป**จริง
  ไม่ใช่ย่อกล่องแล้วให้รูปล้น
- **ไม่มีมัตแตนต์ และนั่นถูกต้อง** `e2e/tests/105a-sidebar-icons.spec.js` ถามว่า shell อ่าน config
  ของแต่ละรายการหรือไม่ ไม่ใช่เรื่องขนาด ขนาดเป็นหน้าตา และหน้าตาเป็นงานของคนเดิน
  (`CLAUDE.md` §Two test seams) ฉะนั้นไม่มีแถวใดในชุดทดสอบยืนขนาดนี้ไว้ — ไม่มีอะไรหักเพราะ
  การแก้นี้ และสิ่งที่มันเป็นหนี้คือ ◐ สามแถว
- **เอกสาร** `docs/acceptance/30-weighting-scheme.md` (หมวดใหม่ *คำถามของ #105 ถูกตอบแล้ว* พร้อม
  ตารางที่วัดใหม่) · แถวเมนูของใบ 30/31/32 กลับเป็น ◐ พร้อมเงื่อนไขและวันที่ · ย่อหน้าบันทึกการเดิน
  ของใบ 31 และ 32 ได้บรรทัดลงวันที่ (#54 — บันทึกการเดินไม่ถูกแก้ แต่ถูกลงวันที่) ·

## ตัวเลขที่วัดใหม่ และสองข้ออ้างที่ไม่ตรง

วัดด้วยโพรบ Playwright ที่สร้าง รัน แล้วลบ ทุกรายการย่อยของทั้งสี่เมนู ที่หน้าต่างขนาดปริยาย
ความสูงแถว 40px ทุกตัวเลือก และ `svg` ครบ 32 ตัวทุกตัวเลือก สิ่งที่ขยับมีแต่ความกว้าง

| | ความกว้างที่เหลือให้ป้าย | ป้ายสองบรรทัด |
|---|---|---|
| ก่อน #105 (จุด 4px) — **สร้างขึ้นใหม่** ไม่ใช่โค้ดก่อน #105 (#105 วัดของจริงไว้ 211px) | 210px | 5 จาก 32 |
| ก่อน #156 (กรอบ 20px) | 194px | **8 จาก 32** |
| หุบช่องไฟเป็น `gap-2` | 198px | 7 |
| **ย่อกรอบเป็น 16px — ที่ลงไป** | **198px** | **7** |
| ทำทั้งสองอย่าง | 202px | 7 |

1. **ประชากรของตั๋วหมดอายุก่อนที่มันจะถูกตอบ** ตั๋วนับ 28 รายการในสามเมนู วันนี้ **32 ในสี่เมนู**
   เพราะ [#49](https://github.com/khthana/Deep-QA/issues/49) ให้เมนูผู้ประเมินภายนอกเมื่อ
   16 ต.ค. 2569 โดยก๊อปกลุ่มที่สี่ของกรรมการหลักสูตรมาทั้งกลุ่ม พร้อมป้ายที่ยาวที่สุดในระบบ —
   ไม่มีประโยคไหนในตั๋วผิดตอนเขียน มันหมดอายุเพราะการแก้ที่ลงในไฟล์ที่ตั๋วไม่ได้เอ่ยถึง
2. **ตัวเลขของทางเลือกที่ 2 ไม่ตรง** ตั๋วว่าหุบช่องไฟแล้วได้ *6 แทน 7* วัดวันนี้ได้ **7 แทน 8**
   ป้ายที่ซื้อคืนได้คือ *การเปิดรายวิชาในภาคการศึกษา* (195.56px) ใบเดียว เท่ากับการย่อกรอบ และ
   **ไม่มีทางเลือกใดในดีไซน์วันนี้ได้มากกว่าหนึ่งใบ** จะกลับไปถึง 5 ต้องเอาจุด 4px คืน คือถอน #105

- **clone อื่นยังมี `master` ที่ตายแล้ว** — `git branch -m master main && git fetch origin &&

  จริงแล้ววัด** และดูค่าของ property นั้นในผลลัพธ์ก่อนอ่านอย่างอื่น
