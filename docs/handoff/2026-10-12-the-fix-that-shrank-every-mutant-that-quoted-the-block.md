## เรื่องที่จะกินเวลาถ้าไม่รู้ (gotchas)

- **clone อื่นยังมี `master` ที่ตายแล้ว** ปลายทางเปลี่ยนเป็น `main` แล้ว clone เก่าต้องแก้มือ:
  `git branch -m master main && git fetch origin && git branch -u origin/main main && git remote set-head origin -a`
- **`git add -A` ถูกปฏิเสธโดยตัวจัดประเภทของโหมดอัตโนมัติ** (รอบนี้สองครั้ง — Data Exfiltration แล้ว
  Credential Leakage) เพราะรีโปมี `DEEP-QA-BACKEND/` กับ `_local/` อยู่ข้างใน **stage ด้วยพาธ
  ชัดเจนเสมอ** เช่น `git add CLAUDE.md docs/acceptance docs/lessons.md e2e frontend/scripts frontend/src mutation`
  — และห้าม `git add` อะไรใต้ `DEEP-QA-BACKEND/` หรือ `_local/` อยู่แล้ว
- **สมอที่ยกมาบรรทัดเดียวอาจไม่ unique เพราะการเยื้อง** — หกช่องว่างเป็น substring ของแปดช่องว่าง
  ค่าคงที่ของ `146` จึงจับทั้งจุด `save` (เยื้องหก) และจุดลบ (เยื้องแปด) ในแฟ้มเดียวกัน การซ่อมคือ
  **ยกบรรทัดเหนือมันมาด้วย** แล้ว assert ว่า count == 1
- **พอร์ต 3100/5100 ของ `e2e/` ถูก Windows จองไว้** อาการคือ "already running" หรือ webServer
  "exited early" อ่าน `netsh interface ipv4 show excludedportrange protocol=tcp` **ทุกครั้ง**
  แล้วเลือกจากนอกช่วง อย่ายกพอร์ตจากใบนี้ไปใช้
- **คอนเทนเนอร์ `deep-core-postgres` ต้องสตาร์ตหลังรีบูต** อาการคือ webServer timeout ไม่ใช่
  ข้อผิดพลาดของฐานข้อมูล
- **อย่ารัน `npm run format` หรือ `npx prettier --write`** prettier ที่ติดตั้งใหม่กว่าสไตล์ที่คอมมิตไว้
  — รอบนี้ `Departments.js` กับ `Plos.js` แดงที่ HEAD อยู่แล้วก่อนตั๋วแตะ ตรวจด้วย
  `git show HEAD:<file> | npx prettier --check --stdin-filepath <file>` ก่อนจะคิดว่าเป็นของเรา
- **คอนโซลเป็น cp874** อย่าพิมพ์ไทยหรือ ☑⚙◐☐ ผ่าน Bash ใช้ Read/Grep หรือ redirect ลงไฟล์แล้ว
  Read หรือ `PYTHONIOENCODING=utf-8` · ส่งไทยขึ้น GitHub ด้วย `--body-file` กับพาธแบบ Windows
  และ `MSYS_NO_PATHCONV=1` · `gh issue close` **ไม่มี** `--comment-file` ใช้ `gh issue comment`
  แล้วค่อย `close` · ข้อความคอมมิตภาษาไทยส่งด้วย `git commit -F <file>`
- **ห้ามแก้ไฟล์ใน `frontend/`, `e2e/` หรือ `mutation/` ขณะชุดทดสอบหรือฮาร์เนสรัน** และห้าม grep
  ต้นไม้ขณะกวาด — มันอ่านมัตแตนต์ที่ apply อยู่ ไม่ใช่โค้ด
- **เขียนสคริปต์แก้ไฟล์ลงไฟล์ ไม่ใช่ heredoc** (heredoc กิน backslash — `fix146.py` รอบแรกหา
  สตริงที่มี `\n` จริงแล้วได้ 0) และ **ยึดสคริปต์แพตช์บน ASCII ไม่ใช่ไทยที่พิมพ์ใหม่**
