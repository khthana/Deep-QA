  (`RolesCell` ใน `frontend/src/pages/Users.js`) · ตารางวัดทุกทางกับคำถามสามข้ออยู่ในคอมเมนต์ปิดของตั๋ว · ชุดเต็ม 1143/1143 ผ่าน 1.3 ชม.

## สิ่งที่ยังค้าง

- **ตั๋วที่เปิด** นับจากตัวติดตาม (`gh issue list --state open --limit 100`) ไม่ใช่จากรายการนี้ · ณ วันนี้มีแค่ **#1**
  ซึ่งเป็นสเปค ไม่ใช่งาน · ไม่มีตั๋วงานเปิด
- **แถวเดินมือของ #310** สี่แถว — **เดินแล้ว 26 พ.ย. 2569 (`c9800f9`) ☑ ทั้งสี่** สองแถวเลื่อนเดินที่ 1150 ไม่ใช่ 1440
  เพราะ side panel ของ extension กินความกว้าง
- **แผ่นเดินมือของ #294** และแถว ☐/◐ ของ #302–#309 — นับจากคอลัมน์เครื่องหมายของใบรับงาน ไม่ใช่จากใบนี้ · **เดินแล้ว 26 พ.ย. 2569**
  (`870afba` ถึง `79c52b8`) เหลือครึ่ง *เข้าสู่ระบบด้วย Google* ของ 305.7 ซึ่งต้องใช้บัญชี Google จริง · แผ่น #294 ไม่มีคอลัมน์เครื่องหมาย
  การนับคิวจากคอลัมน์จึงมองไม่เห็นมัน ต้องเปิดตารางบันทึกผลของแผ่นดู
- **ตัวอักษรของตัวย่อบทบาท** (`SA` `FA` `DA` `PM` `T` `EA` ใน `components/MapRole.js`) เป็นถ้อยคำของเจ้าของงาน ชุดที่ใช้คือชุดที่วัด
- **ข้อจำกัดของ #310** — tooltip ของ `abbr` เปิดได้ด้วยเมาส์เท่านั้น แป้นพิมพ์ยังเปิดไม่ได้ · ไม่มีตั๋ว ถ้าจะแก้ต้องถามเจ้าของงานก่อน
  เพราะเป็นการเปลี่ยน UI (`docs/06` §Out of Scope) · **ตอบแล้ว**: เจ้าของงานตอบเมื่อ 26 พ.ย. 2569 ว่า *ถูกแล้ว*: tooltip ที่เปิดได้ด้วยเมาส์อย่างเดียวคือพฤติกรรมที่ต้องการ ไม่ใช่ข้อบกพร่อง
- **สามเรื่องหน้าตาที่จอแคบ** จากภาพโพรบของการเดิน 26 พ.ย. 2569 ไม่ใช่เกณฑ์ของ #302–#309 (แถวเหล่านั้นผ่าน):
  ก. ตารางของ `/main/users/user-history` ที่ 390 แน่น ทุกคอลัมน์ตัดสามบรรทัด · **ตอบแล้ว 27 พ.ย. 2569: รับได้**
  เพราะใช้งานจริงที่ 1920 · ข. ปุ่มกลมพับเมนูข้างโผล่ครึ่งวงที่ขอบซ้ายทับการ์ด ทุกหน้าเมื่อพับเมนูบนจอแคบ (เห็นที่ 375 และ 360)
  · ค. เบราว์เซอร์ตัด *ผู้ใช้|งาน* กลางคำ — หัวเรื่องและปุ่มของ `/main/users/user-history` ที่ 390 และปุ่มนำเข้ากับปุ่มเพิ่มของ
  `/main/users` ที่ 360 · ข และ ค ยังไม่ได้ถาม ไม่มีตั๋ว และยังไม่ได้เทียบกับ `DEEP-QA-FRONTEND` ว่าเดิมเป็นแบบเดียวกันไหม
- **นับฐานข้อมูลจริงบน production** (จากใบก่อน, 21 พ.ย. 2569) — ใบนี้ไม่ได้ถามต่อ สถานะไม่ทราบ ถามเจ้าของงานก่อนทำ

## สิ่งที่จะเสียเวลาถ้าไม่รู้

- **ชุดเต็มใช้ 1.3 ชม.** ที่ 1143 แถว — รันผ่าน PowerShell tool กับ `$env:E2E_BACKEND_PORT='3150'` (พอร์ต 3100 เป็น SSH tunnel ของ
  เจ้าของงาน ห้ามฆ่า)
- **log ที่ redirect จาก PowerShell** อาจเป็น UTF-16LE หรือ UTF-8 มี BOM — ดู BOM ก่อนอ่าน การเดาผิดทางให้ผลว่างหรือขยะ ไม่ใช่ error
- **Postgres หยุดหลังรีบูต** อ่านเป็น webServer timeout — `docker start deep-core-postgres`
- **clone บนเครื่องอื่น** ที่ยังมี `master` (เปลี่ยนชื่อเป็น `main` 17 ส.ค. 2569) ต้องแก้ด้วยมือ:
  ```bash
  git branch -m master main && git fetch origin --prune && git branch -u origin/main main
  ```
