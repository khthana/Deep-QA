ใบนี้แทนที่ `2026-11-22-the-row-that-came-in-by-the-menu.md` สำหรับเรื่องสถานะ และใบนั้นยังถูกต้องในฐานะ
**บันทึกของวันนั้น** (#54) ลูกโซ่ของสถานะคือใบนี้ → ใบนั้น → ย้อนตามลูกโซ่ต่อไป · เซสชันที่เขียนใบนี้ทำ #307–#310 ·
#301–#306 ปิดในเซสชันก่อนหน้าโดยไม่มีใบส่งมอบ สถานะของมันอ่านจากคอมเมนต์ปิดของตั๋วแต่ละใบ

**สิ่งที่ขยับ (อ่านจากตั๋ว ไม่ใช่จากที่นี่)**

- **#301** — หกแถวในห้าแฟ้มอ่านค่าที่ฟอร์มแก้ไขวาดแล้ว ไม่ใช่เฟรมว่าง (`a48b777`)
- **#302–#306** — หน้าผู้ใช้กลับไปเป็น UI แบบเดิมตามกฎของเจ้าของงานใน `docs/users-screen.md` · ตาราง หน้าแก้ไข
  กล่องเพิ่ม ประวัติ และการลบบัญชีที่ไม่มีอะไรอ้างถึง (#306)
- **#307** — กล่องเพิ่มบัญชีมีสถานะปฏิเสธของตัวเอง (คำตอบของเจ้าของงาน ข.)
- **#308** — เก็บ route ประวัติรายบัญชีไว้ (คำตอบของเจ้าของงาน)
- **#309** — ทุกหน้าในตั๋วได้การ์ดและหัวเรื่องแบบเดิม · census `content-titles.js` ต่อสายแล้ว
- **#310** — แถวของตารางผู้ใช้สูงบรรทัดเดียวที่ 1920 · คอลัมน์บทบาทเป็นตัวย่ออังกฤษ ขอบเขตไป tooltip และชื่อที่เข้าถึงได้ของช่อง
  (`RolesCell` ใน `frontend/src/pages/Users.js`) · ตารางวัดทุกทางกับคำถามสามข้ออยู่ในคอมเมนต์ปิดของตั๋ว · ชุดเต็ม 1143/1143 ผ่าน 1.3 ชม.

## สิ่งที่ยังค้าง

- **ตั๋วที่เปิด** นับจากตัวติดตาม (`gh issue list --state open --limit 100`) ไม่ใช่จากรายการนี้ · ณ วันนี้มีแค่ **#1**
  ซึ่งเป็นสเปค ไม่ใช่งาน · ไม่มีตั๋วงานเปิด
- **แถวเดินมือของ #310** สี่แถว ☐ ใน `docs/acceptance/11-user-accounts.md` §#310 — เส้นใต้ประของตัวย่อ · ชี้เมาส์แล้วเห็น tooltip ·
  ที่ 1440 เลื่อนตารางได้ถึง *ดำเนินการ* · กดปุ่มของคอลัมน์นั้นได้หลังเลื่อน
- **แผ่นเดินมือของ #294** และแถว ☐/◐ ของ #302–#309 — นับจากคอลัมน์เครื่องหมายของใบรับงาน ไม่ใช่จากใบนี้
- **ตัวอักษรของตัวย่อบทบาท** (`SA` `FA` `DA` `PM` `T` `EA` ใน `components/MapRole.js`) เป็นถ้อยคำของเจ้าของงาน ชุดที่ใช้คือชุดที่วัด
- **ข้อจำกัดของ #310** — tooltip ของ `abbr` เปิดได้ด้วยเมาส์เท่านั้น แป้นพิมพ์ยังเปิดไม่ได้ · ไม่มีตั๋ว ถ้าจะแก้ต้องถามเจ้าของงานก่อน
  เพราะเป็นการเปลี่ยน UI (`docs/06` §Out of Scope)
- **นับฐานข้อมูลจริงบน production** (จากใบก่อน, 21 พ.ย. 2569) — ใบนี้ไม่ได้ถามต่อ สถานะไม่ทราบ ถามเจ้าของงานก่อนทำ

## สิ่งที่จะเสียเวลาถ้าไม่รู้

- **ชุดเต็มใช้ 1.3 ชม.** ที่ 1143 แถว — รันผ่าน PowerShell tool กับ `$env:E2E_BACKEND_PORT='3150'` (พอร์ต 3100 เป็น SSH tunnel ของ
  เจ้าของงาน ห้ามฆ่า)
- **log ที่ redirect จาก PowerShell** อาจเป็น UTF-16LE หรือ UTF-8 มี BOM — ดู BOM ก่อนอ่าน การเดาผิดทางให้ผลว่างหรือขยะ ไม่ใช่ error
- **Postgres หยุดหลังรีบูต** อ่านเป็น webServer timeout — `docker start deep-core-postgres`
- **clone บนเครื่องอื่น** ที่ยังมี `master` (เปลี่ยนชื่อเป็น `main` 17 ส.ค. 2569) ต้องแก้ด้วยมือ:
  ```bash
  git branch -m master main && git fetch origin --prune && git branch -u origin/main main
  ```
