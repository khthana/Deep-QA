## 5. กับดักที่เพิ่มจากฉบับก่อน

- **อย่าตรวจว่า backend รู้จัก route ใหม่ด้วยการ `curl` แบบไม่เข้าระบบ** ทุก path ใต้ `/api`
  ที่ไม่ได้เข้าระบบตอบ **401 เหมือนกันหมด** เพราะด่าน session อยู่ก่อนการ routing
  401 จึงไม่ได้แปลว่า route มีอยู่ **ต้อง login ก่อนแล้วยิง และต้องได้ 200 พร้อมข้อมูลจริง**
  รอบนี้เสียเวลาไปสองรอบเพราะข้อนี้
- **process ที่ค้างบนพอร์ตอาจเป็นของ agent ไม่ใช่ของคน** background task ที่สั่งไว้ก่อนหน้า
  รันเป็น `cmd.exe /d /s /c node server.js` ซึ่งหน้าตาเหมือน terminal ของคน
  Ctrl+C ในหน้าต่างของคนจึงไม่ทำอะไรเลย **ดู PID กับเวลาที่ process เกิดก่อนสรุปว่าใครถือพอร์ตอยู่**
- **ในข้อความไทยบน JSX ห้ามขึ้นบรรทัดใหม่กลางคำ** JSX ต่อบรรทัดด้วยช่องว่างหนึ่งตัวเสมอ
- **A fresh clone lands on a dead `master`.** Run, verbatim:
  `git branch -m master main && git fetch origin --prune && git branch -u origin/main main`
