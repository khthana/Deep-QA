1. เติม **Test Data ชุดจริง** (รหัสผู้ใช้/นักศึกษาจริงในระบบทดสอบ) ลงในทุก precondition
2. แตก Test Step ให้ละเอียดระดับ click-by-click สำหรับกรณี P1 ทั้งหมด
3. เพิ่ม **API-level test case** อ้างอิงจาก Sequence Diagram §3.6 (รูป 3.85–3.94) โดยเฉพาะ `POST /api/insert` และ endpoint การคำนวณคะแนน CLO/PLO
4. เพิ่ม **Regression suite** สำหรับสูตรคำนวณคะแนน (คะแนนดิบ → CLO สเกล 5 → PLO)
5. เพิ่ม cross-browser และ responsive test (การออกแบบปัจจุบันอิงหน้าจอ Desktop)
6. ปิด Open Questions Q1–Q10 แล้วปรับ Expected Result ให้ชี้ชัด
